================================================================
  项目备份工具  使用说明
================================================================

这个文件夹里有两个工具，双击 .bat 就能用：

    backup.bat      存档：把当前改动保存下来，并上传到 GitHub
    rollback.bat    读档：把项目退回上一个存档


----------------------------------------------------------------
  一、什么时候用 backup.bat
----------------------------------------------------------------

  · 做完一个能跑起来的功能之后
  · 调好了一个手感之后
  · 让 AI 做一次大改动之前   <-- 这一条最重要

  双击后会问你一句话："这次改了什么"，随便写就行，比如：

      做好了完美格挡
      调整了角色移动速度

  然后它会自动存档并上传。看到 "BACKUP COMPLETE" 就是成功了。


----------------------------------------------------------------
  二、什么时候用 rollback.bat
----------------------------------------------------------------

  改坏了、资源丢了、AI 把项目改乱了 —— 双击它。

  它会列出最近的存档，你输一个数字就退回去了。
  它会先把你"当前的状态"也存一份，所以退错了还能再回来。


----------------------------------------------------------------
  三、三个必须知道的事
----------------------------------------------------------------

  1. UE 编辑器里没保存的内容，存档工具看不到。
     所以双击 backup.bat 之前，先在编辑器里按 Ctrl+S。

  2. 上传失败不用慌。改动已经存在你电脑上了，不会丢。
     等网络好了再双击一次 backup.bat 就行。

  3. 不要删除项目根目录下的 .git 隐藏文件夹，所有存档都在里面。


----------------------------------------------------------------
  四、如果提示要登录 GitHub
----------------------------------------------------------------

  打开 PowerShell，粘贴执行下面这行，然后按提示在浏览器里登录：

      git credential-manager github login --username LadyStardust59 --browser


----------------------------------------------------------------
  五、更详细的说明
----------------------------------------------------------------

  任何时候不确定，就停下来问 AI 助手，不要自己乱试。
