## 1. 设计目标与坐标

### 1.1 要什么、不要什么

| 要（Do） | 不要（Don't） |
|---|---|
| 每一段攻防都留出「读招 → 选择」的时间 | 纯反应速度的 QTE 化战斗 |
| 主动权在敌我之间**来回易手**，且易手原因可归因 | 玩家单方面压制（敌人只是靶子） |
| 玩家的每一次成功防守都能**兑换**成进攻机会 | 防守永远只是止损（魂系的被动感） |
| 敌方也有资源、也会喘、也会过热 | 敌人拥有无限资源与无成本霸体 |
| 换人 = 换节奏带（策略选择） | 换人 = 三条命 / 无脑换血流 |
| 演出承担**信息功能**（预兆、优先级、状态） | 演出只是炫技与干扰 |

### 1.2 中速的量化定义

「中速」不是感觉，是可以被指标约束的：

| 指标 | 目标值 | 说明 |
|---|---|---|
| 单次敌招「预兆 → 生效」窗口 | 重击 0.55~0.9s / 快攻 0.25~0.4s / 投技 0.4~0.6s | 低于 0.25s 属于反应阈以下，禁止出现在主线 |
| 单次攻防交互时长 | 1.5~4s | 从敌方起手到我方结算完毕 |
| 主动权易手频率（人形 Boss） | 每 12~20s 一次必然易手 | 保证「节奏可感知」 |
| 对峙探测带占比 | 总战斗时长的 20%~30% | 呼吸位，也是换人与调整构筑的窗口 |
| 玩家决策密度 | 每 10s 至少 3 次有意义选择 | 低于此值即退化为「按键流水线」 |
| 期望 TTK（人形 Boss） | 5.5~7 min | 见 `07` 图数值仪表 |

## 2. 底层公理与统一模型

### 2.1 三条公理（作用于所有实体，包括玩家）

1. **资源不会自然回满**：任何资源的恢复都必须通过「正确的行为」换取（进攻、成功防御、换人轮换）。Boss 无自愈，仅在阶段切换时刷新护甲。
2. **攻击是最好的防御**：进攻行为同时产出三种收益 —— 削敌反制值、消耗敌体力、回充我方气力。这条公理保证了「主动」在数值上总是略优于「被动」，从而把游戏从中速推向**双向压制**而非「守方等待」。
3. **每个资源都有独立的「被压制惩罚」**：被压制时，回气 −40%、决意条加速积累（既是惩罚也是脱出资源）、力竭风险上升。主动权因此是有数值重量的东西，而不是抽象概念。

### 2.2 敌我同构（同构但不对称）

玩家与敌人共用同一套模型，区别只是参数与 AI：

```
实体(Entity)
├─ 生命层：VP / 部位耐久            ← 玩家的 VP 极难回复；Boss 无自愈
├─ 代谢层：行动值 AP / 气力 / 体力   ← 玩家的 AP 有回复曲线；Boss 的体力是出招预算
├─ 架势层：韧性 / 反制值（架势）      ← 满值 → 破绽（硬直 2~4s）
├─ 资源层：决意条 / 情绪 / 大招槽     ← Boss 侧对应「阶段 / 觉醒 / 召唤」
└─ 节奏层：节奏表（AI 出招牌组权重）   ← Boss 侧是 AI；玩家侧是「武器连段树」
```

**为什么必须同构**：只有同构，玩家才能通过观察自己的资源逻辑去推断敌人的逻辑 —— 这是「读招」这件事在系统层面成立的前提，也是《万物契约》式「通用规则 + 单位差异」思路的工程化表达。

## 3. 玩家侧：资源、行为与承诺

### 3.1 资源清单

| 资源 | 上限 / 基线 | 来源 | 消耗 | 被压制惩罚 |
|---|---|---|---|---|
| **生命 VP** | 每角色独立 | 关卡补给 / 回复技 / 换人轮换 | 被命中、环境、破绽惩罚 | 无（但全队共享治疗资源） |
| **行动值 AP** | 100（时间 +9/s；普攻命中 +6；完美闪避返还 50%） | 时间与进攻 | 闪避 −20 / 蓄力 −35 / 技能 −15~40 / 起手取消 −10 | 回气 −40%；不足 → **力竭**（移速 −35%、无法闪避、受创 +25%） |
| **气力** | 100（仅进攻行为回充：普攻命中/被格挡 +4、完美格挡 +12、连段终结 +20、打断敌起手 +15） | 进攻 | 重击 −25 / 破防技 −40 / 蓄力斩 −60 | 同上（回充速率下降） |
| **韧性** | 100（玩家自身的架势） | 时间 +5/s | 被击中、被破防技 | 归零 → 玩家被破防（2s 硬直，敌方免费连段） |
| **破绽槽** | 100（**仅在敌破绽态**可积累） | 破绽窗口内命中 | 无 | 无 |
| **决意条** | 0~3 格 | 受击、完美格挡、濒死 | 脱离连段（1 格）/ 打断敌起手（1 格）/ 处决加速（2 格） | **加速积累**（这是玩家的保命资源） |
| **情绪** | 100 | 成功攻防（命中、完美格挡、打断、破绽） | 变身（50）/ 流派技（30） | 获取速率减半 |
| **大招槽** | 100 | 造成伤害、承受伤害、换人 | 共鸣技 / 无双技 | 无 |
| **共鸣槽**（队伍共享） | 100 | 换人、连携终结、机制完成 | 三人共鸣技（100） | 无 |

### 3.2 行动的承诺成本（Commitment）—— 中速的核心

中速感来源于**每一个动作都有真实的收招与取消成本**。以下是基线帧数（60fps）：

| 行动 | 前摇 | 有效 | 收招 | 可取消窗口 | 备注 |
|---|---|---|---|---|---|
| 轻击 | 7f | 4f | 12f | 12f | 低承诺，用于试探与削气 |
| 重击 | 22f | 6f | 30f | 无（除命中） | 高承诺，破轻霸体 |
| 蓄力斩 | 40f+ | 8f | 34f | 蓄力中可取消（损失气力） | 破重霸体，代价最大 |
| 闪避 | 3f | 无敌 11f | 30f | — | 消耗 AP 20，连闪两次即力竭 |
| 格挡 | 1f | 持续 | 10f | — | 每段 −8 AP，可被破防 |
| 完美格挡 | 1f | **6f** | 10f | 立即反打 | 敌反制值 +18、敌硬直 0.4s、气力 +12 |
| 换人 | 4f | 依时机 | 8f | — | 见第 5 节 |
| 技能 | 12~20f | 依技能 | 18~26f | 部分 | 消耗气力 |

> **设计意图**：玩家不能无脑连点。每一次「按下去」都是一次投资 —— 这正是中速博弈与高速 ACT 的分水岭。

### 3.3 玩家的一条完整连段（示例：重剑「断岳」）

```
轻击 → 轻击 → 重击（破轻霸体）
      ↘ 在重击命中瞬间取消 → 破防技（−40 气力，敌反制值 +60）
                              ↘ 若敌进入破绽 → 处决（8~12% 最大生命）
                              ↘ 否则 → 连携换人，把连段交给队友继续削反制值
```

## 4. 敌方侧：资源、霸体与 AI 策略组

### 4.1 敌方资源

| 资源 | 设计要点 |
|---|---|
| **生命 / 部位耐久** | 巨型单位的**腿座**按部位（三处腿甲各 800 耐久）独立结算；躯干与核心走反制值，不单独记耐久。破坏部位会改变 AI 牌组与演出 |
| **反制值（架势）** | 上升：被攻击 +3 / 被完美格挡 +18 / 起手被断 +25；下降：时间 −2/s（脱战 3s 后恢复衰减）。处决命中后**重置为 0**。满值 → 破绽（硬直 2~4s，进入可处决窗口）。满值基线：杂兵 **60**（一击即破）/ 人形 Boss **600** / 巨型躯干 **1200**。人形 Boss 首次满值仅跪地 0.8s（起手招式硬直），第二次起才是可处决破绽 |
| **体力** | 敌方出招预算。耗尽 → **喘息 2.2s**（长收招，玩家的稳定确反窗口）。这是「读招」之外的第二条破局路径 |
| **霸体分级** | 无 / 轻（重击可破）/ 重（仅破防技与处决可破）。霸体分级的存在让「硬顶」成为敌人的一种合法策略 |
| **节奏表** | AI 的出招牌组与权重。会因阶段、受创、玩家行为而变化（见 4.3） |
| **联动度（双 Boss 专属）** | 0~100。上升：共斗技命中 +15 / 互相掩护 +10 / 玩家被夹击 +8 / 玩家阵亡一位 +25；下降：打断合击 −30 / 打断交换阵 −20 / 破坏镜面投影 −15 / 单侧连续承伤 −5/s；任一方被处决时额外 −40（防滚雪球） |

### 4.2 三条破局路径（敌方资源的三处泄漏点）

| 路径 | 手法 | 收益 | 适用 | 对应武器取向 |
|---|---|---|---|---|
| ① 反制值破防 | 连续进攻 / 完美格挡 | 破绽 2~4s → 处决 8~12% 最大生命 | Boss 破绽窗口、群体清场 | 双刃 / 长枪（多段低伤 + 高削气） |
| ② 体力耗尽 | 诱导出招 / 位移骗空招 | 喘息 2.2s → 确反连段，主动权 +2 档 | 人形 Boss、双 Boss 交换阵 | 太刀 / 双拐（短收招、高机动） |
| ③ 牌组读穿 | 识别同预兆的不同分支 | 主动权直接反转 + 敌方节奏表降权 | 熟练玩家上限操作 | 全部（本质是知识，不是数值） |

### 4.3 AI 架构：三层决策（这是「可读」的技术保证）

```
第 3 层  编队层（双 Boss / 群体专用）
         输出：阵型意图（压制 / 包夹 / 交换 / 合一）+ 发言权令牌（同一时刻只有一人可高威胁前摇）
              ↓
第 2 层  战术层（Utility Scoring）
         输入：距离、玩家姿态、玩家 AP/气力、自身反制值与体力、阶段
         输出：候选招式评分 → 选牌
              ↓
第 1 层  执行层（牌组 = 可分支的动作卡）
         输入：玩家位置 / 资源 / 行为记录
         输出：具体分支（A 默认 / B 读位 / C 资源触发）+ 预兆播放
```

**硬约束（写进代码，不由策划单人把关）**：
- 同一时刻只有一个实体拥有「高威胁前摇发言权」（防双 Boss 同时读条；包夹阵等双人威胁必须**错峰 0.4s 以上**）；
- 每个招式必须绑定一个预兆资源（VFX + 音效 + 地面纹理）；
- 每个预兆必须至少注册两个「正确解」，否则不允许入表；
- 敌方任何「恢复类」行为都必须付出可见代价（例：人形 Boss 体力 < 30 时是**自伤 3% 生命换回 25 体力**，而不是免费调息）；
- 每 20s 至少一次「演出级」大招（节奏起伏锚点，避免长时间平淡）。

**人形 Boss 的三组评分规则（示例，见 `07` 图）**

| 组 | 规则样例 |
|---|---|
| A · 距离与姿态 | `if 距离 > 6m && 机动权可用 → 突进/剑气 ×1.6`；`if 玩家连续后撤 2 次 → 封锁技 ×2.2` |
| B · 玩家行为反制 | 记录格挡率 / 完美格挡成功率 / 常用闪避方向；`格挡率高 → 投技与不可格挡技 ×1.7`；`常用左闪 → 分支改左向横扫` |
| C · 资源与节奏 | `体力 < 30 → 自伤 3% 生命换回 25 体力（1.2s 前摇，露出确反窗口）`；`反制值 > 70% → 主动拉开距离（自然衰减 −40%，玩家可突进惩罚）`；`玩家 AP < 25 → 加压连段 ×2.0` |

> **注意 C 组的第二条**：Boss 会主动「避免被破防」。这看起来是 AI 变聪明，实质是给玩家一个可读的反制点 —— 它一旦拉开距离，玩家就能用剑气/远程/突进技惩罚它的自保行为。**AI 越有策略，读招越有深度。**

## 5. 节奏系统：主动权轴与五带

### 5.1 主动权轴

```
崩坏 ──── 劣势 ──── 对峙 ──── 优势 ──── 绝对优势
被连段    守势解算   互相试探   压制连段   破绽/处决
```

主动权是一个**连续值**（不是布尔），由每次攻防结算推动。UI 上以一条细轴呈现（见 `03` 图），玩家可以随时知道「现在谁在带着节奏」。

### 5.2 节奏五带

| 带 | 时长 | 主动权 | 玩家决策点 | 节奏意图 |
|---|---|---|---|---|
| ① 对峙探测 | 3~8s | 争夺中 | 先手还是让先？哪把武器开节奏？ | 建立读招基础，把敌方的「牌」逼出来 |
| ② 压制连续 | 4~12s | 玩家侧 | 续连（吃 AP）还是收招回气？ | 把优势兑换成敌方的资源赤字 |
| ③ 守势解算 | 2~6s | 敌方侧 | 硬防换气力，还是软防换位置？ | 格斗游戏式的「守方选择题」 |
| ④ 反转窗口 | 1.5~4s | 急剧回摆 | 确反连段、处决，还是换人接力？ | 让主动权被「抢」回来，而不是等回来 |
| ⑤ 终结窗口 | 3~6s | 绝对优势 | 伤害最大化，还是安全收招？ | 把 30~60s 的博弈兑现成一次爽点 |

### 5.3 状态转移与三重防滚雪球

转移规则见 `03` 图。特别强调**防滚雪球的三道闸门**，这是中速博弈不退化成「一边倒」的保险：

1. **强制拉开**：每次终结窗口结束，双方获得 1.2s 无敌帧并强制拉开距离，主动权指针回到对峙区。
2. **资源反噬**：压制方在压制层数 ≥4 时，自身 AP 回复 −25%，敌方反制值回充 +30%。
3. **脱出权**：被压制方可支付决意条（0~3）脱离连段，每次支付后清空并进入 20s 冷却。

## 6. 敌我交互流程（核心博弈桌）

完整表格见 `04` 图。这里说明**设计红线与教学逻辑**：

**四条红线**
1. 每个敌招必须有唯一预兆（红光=重击可格挡 / 黄光=多段快攻 / 紫光=投技不可格挡 / 金紫=觉醒全场，全场仅此 4 色）；
2. 每个预兆至少两个正确解；
3. 每个正确解都必须付出资源或位置代价（否则最优解退化）；
4. 同一预兆在不同阶段 / 编队下可换分支 —— 这是「读招的第二层」。

**溃败分支必须存在，但必须可读出**：预兆缺失或超出反应阈的招式，走「场地读招」而非「反应读招」（提前位移、换人开领域、用环境物处理）。绝对禁止纯随机、无预兆的秒杀。

**教学节奏**（前 30 分钟）
- 0~5 min：杂兵 —— 只教「轻击 → 重击 → 破防」与红/黄光识别；
- 5~12 min：精英 —— 教「完美格挡 → 反打」，第一次体验主动权反转；
- 12~20 min：第一个小 Boss —— 教「体力耗尽 → 确反」与「换人连携」；
- 20~30 min：人形 Boss 阶段 1 —— 教「同一预兆的不同分支」与「读招的第二层」。

## 7. 换人系统：差异化与节奏重置

### 7.1 不是三条命，而是三种节奏工具

| 位置 | 角色 | 职责 | 专属资源改写 | 换出收益 |
|---|---|---|---|---|
| 先手位 · 压制者 | 重剑「断岳」 | 开局抢主动权、堆压制层数、削反制值 | 气力上限 +30%，完美格挡回气翻倍 | 换出时向进入方转移 1 层压制 |
| 中枢位 · 读招者 | 太刀「霜切」 | 中段接管，处理敌方第二阶段牌组 | 决意条上限 +1（可多脱离一次） | 离场时留下 3s 缓速领域（敌 −20% 移速） |
| 收尾位 · 爆发者 | 双刃「离火」 | 破绽窗口与处决、终结技兑现伤害 | 情绪获取 +25%，变身需求降低 | 入场自带 2s「追击」（连段 +15%） |

### 7.2 三种换人类型（同一按键，由时机决定结果）

| 类型 | 时机窗口 | 效果 | 代价 |
|---|---|---|---|
| **连携换人 COMBO SWAP** | 我方任意可取消帧 / 敌收招窗口 | 入场技继承连段段数并重置计数（Combo 不断） | 入场方 AP −15；被换出方 18s CD |
| **反击换人 COUNTER SWAP** | 敌方起手 60% 内 | 0.35s 子弹时间 + 进入方无敌；反击命中 → 敌强制破绽 | CD 100s；失败则两人同时吃伤（×150%） |
| **援助换人 ASSIST SWAP** | 任意时刻（无无敌帧） | 队友出场放 1 个技能后立即退场，主体不换 | 援助 CD 25s，占用该队友大招槽 50% |
**换人设计红线**
1. 换人必须有代价（CD + 资源 + VP 风险），否则退化为无脑换血流；
2. 换人必须能「改变节奏带」，而不只是换个人输出；
3. 每名角色的入场 / 退场都要有独立演出与音效锚点（玩家必须能「听出」谁上场了）。

### 7.3 与三人 Boss 的接口

| Boss | 换人的战术价值 |
|---|---|
| 人形 Boss | 用「读招者」处理阶段 2 的分支牌组；用「爆发者」兑现残心破绽 |
| 巨型 Boss | 换人 = 位移（无敌落点）→ 规避扫场；用「爆发者」在坍塌节拍兑现 ×1.3 窗口 |
| 双 Boss | **反击换人**是唯一能稳定打断「合一技」的手段；**援助换人**用于补控制打断「交换阵」 |

## 8. 构筑与成长：差异化的四个旋钮

### 8.1 玩家侧三层构筑（同规则、不同表达）

| 层 | 内容 | 改写什么 |
|---|---|---|
| **武器层** | 重剑＝霸体换血 / 太刀＝见切确反 / 双刃＝压制连段 / 长枪＝距离控制 / 双拐＝反击流 | 改写「完美格挡收益、破防技形态、收招可取消帧」三处帧数据参数 |
| **契约兽层** | 火＝命中叠灼烧增伤 / 冰＝减速延长读招窗口 / 雷＝打断强化 / 土＝护甲与霸体 | 改写你的一条**资源规则**（如「AP 回复 +40%」「破防技不耗气」） |
| **风格层** | 压制型（连段 +15%）/ 守势型（格挡收益 +50%）/ 支援型（援助 CD −40%） | 决定你在这支队伍里「想占哪一带」 |

### 8.2 成长系统（长线）

- **技能树**：每条武器线 3 个分支（压制 / 确反 / 支援），关键节点解锁**新牌**（新连段分支）而非纯数值；
- **武器改造**：每把武器 3 个改造槽（改帧数 / 改资源 / 改判定），可重铸；
- **契约兽养成**：等级 → 解锁第 2 条资源改写 → 解锁契约兽技 → 解锁共鸣技；
- **跨角色继承**：解锁的「读招知识类」被动（如「完美格挡后 0.2s 内反打伤害 +20%」）全队共享，鼓励玩家尝试不同角色组合；
- **难度设计**：不靠加血加伤，而是**扩充敌方牌组**（增加分支 C 的触发条件）与**压缩预兆窗口**（−15%）。

## 9. Boss 设计 ①：人形「赤炼 · 刑无咎」

> 完整图见 `07_boss_humanoid.png` 与 `10_humanoid_choreography.png`

### 9.1 定位与设计意图

他是玩家的**镜子**：招式逻辑与玩家同构，但每个起手都有 2~3 条后续分支。胜负关键不是反应速度，而是「识别分支 + 选择正确的解 + 把成功防守兑换成主动权」。三阶段逐步移除玩家的「懒解」（格挡、拉开距离）。

| 属性 | 值 |
|---|---|
| 生命 | 18,000（≈ 6~10 轮压制兑现，每轮 40~60s） |
| 反制值 | 600 满值触发破绽（2.5s）；**首次满值仅跪地 0.8s**（作为教学提示） |
| 体力 | 100；出招 −12~25，耗尽 → 喘息 2.2s |
| 霸体 | 轻霸体（重击可破）/ 终结技重霸体 |
| 弱点 | 背后（破绽延长 0.8s） |
| 契约兽 | 赤炼朱雀（阶段 3 召唤） |

### 9.2 阶段流程

| 阶段 | 血量 | 新增牌组 | 新增机制 | 演出 |
|---|---|---|---|---|
| 1 · 试招 | 100%~70% | 基础三连 + 突进 + 后跳刀气 | 预兆分明，分支仅 2 条 | 缓慢拔刀入鞘，仅太鼓与尺八 |
| 2 · 加压 | 70%~40% | 旋身斩（霸体）/ 拂尘投技 / 残影突刺 / 拔刀居合 | **完美格挡累计 2 次 → 金色「残心」破绽 0.9s**（与「延迟二段」的 ≥3 次计数分开统计） | 面甲裂纹、衣摆燃赤色余烬、鼓点加密 |
| 3 · 焚身 | 40%~15% | 剑气封锁 / 朱雀召唤 / 赤炼领域 | 领域内玩家 AP 消耗 +20%，需破坏领域柱脱困 | 场地起火、镜头拉远、加入人声吟唱 |
| 终局 · 残心相搏 | 15%~0% | 仅留 3 招，但每招可接「残心」二段 | 处决窗口 ×2（各 4s），反制失败会被反处决 | 静音 → 刀鸣 → 单挑式镜头对切 |

> **阶段切换用「血量阈值 + 机制完成」双条件**，避免玩家用爆发直接跳过机制教学段。

### 9.3 出招牌组（读招的第二层）

| 牌面 | 预兆 | 分支 A | 分支 B（读位） | 分支 C（资源触发） | 正确解（至少两个） |
|---|---|---|---|---|---|
| 三段斩 | 红光 · 侧身蓄力 · 铁器摩擦声 | 上→下→突刺 | 上→横扫（玩家在左侧） | 突刺接投技（玩家 AP<25） | 第 2 段完美格挡 / 后撤出突刺距离 |
| 旋身斩 | 黄光 + 轻霸体 · 脚下起尘 | 原地旋身 180° | 旋转追身 360° | 旋转后接剑气封锁 | 破防技打断 / 后跳 |
| 残影突刺 | 白光 · 残影拉长 · 收刀音 | 直线突刺 8m | 折线突刺 2 段 | 突刺后立刻拉距（自保） | 侧向闪避 + 确反 / 完美格挡第 1 段 |
| 剑气封锁 | 青光 · 地面裂纹扩散 | 横向剑气 3 道 | 纵向剑气锁两侧 | 剑气 + 朱雀俯冲合击 | 跳跃 / 换人无敌帧 |
| 赤炼领域 | 全场金紫光 + 吟唱人声 | 领域展开 18s | 领域 + 自身霸体 | 领域 + 召唤朱雀 | 破防打断 / 契约柱净化 |

**预兆色板（全场唯一映射，共 7 类）**：红＝重击（可格挡）/ 黄＝多段快攻 / 金＝投技（不可格挡）/ 白＝直线突进 / 紫＝镜面术 / 青＝领域与召唤 / 金紫＝觉醒全场。绝不混用、绝不破例 —— 这是「可读性」的第一道保险。

## 10. Boss 设计 ②：巨型「墟骸 · 归墟巨像」

> 完整图见 `08_boss_colossal.png` 与 `11_colossal_choreography.png`

### 10.1 定位

巨型单位的通病是「视角灾难 + 血包感」。本设计用三个手段解决：**可攀爬的高度差、可破坏的部位、可被反击的敌方武器**，把巨型 Boss 做成「可解构的舞台谜题」。

### 10.2 三层可解构结构

| 层 | 名称 | 类型 | 耐久 / 机制 | 威胁 | 解法 |
|---|---|---|---|---|---|
| 1 | 腿座「础」 | 部位破坏层 · 入门 | 三处腿甲各 800；破坏 2 处 → 失衡倒地 | 践踏冲击波（地面波纹，必须跳）/ 腿扫（低段，必须跳或绕后） | 集中攻击同一侧腿甲 → 单侧坍塌，巨像向该侧倾斜 6s |
| 2 | 躯干「碑心」 | 反制值层 · 主战场 | 反制值 1200（两次破绽即坍塌）→ 每次跪地 3s | 挥手横扫 / 抓取投技（需挣脱）/ 石块投掷 | 攻击关节（肩/肘连接处，伤害 ×1.8），或用坠落手臂砸击 |
| 3 | 头部核心「墟眼」 | 纯机制层 | 仅在坍塌窗口（8s）可攻击 | 核心射线（扫场，须躲柱后/攀高台）/ 引力吸附 | 共鸣契约柱充能 → 强制失衡 → 破防 → 处决 |

### 10.3 部位破坏流程（一次完整的解构）

1. **腿甲 ×2 破坏** → 失衡倒地 6s → 全队免费输出（伤害 ×1.3）
2. **躯干破绽 ×1** → 跪地 3s + 露关节 → 肩/肘进入可破坏状态
3. **关节 ×1 破坏** → 手臂坠落于场地 → 成为掩体，也可被投掷反击
4. **躯干破绽 ×2** → 整机坍塌 8s → 头部核心进入可攻击状态
5. **核心处决** → 处决演出 + 全层合计最大生命 −10%（每阶段 1 次，共 3 次）→ 强制回场，进入下一阶段

> 巨像最大生命 32,000，按层分配：腿座 8,000 / 躯干 16,000 / 核心 8,000。全战 ≈ 5~7 min，三阶段各占 1/3 左右。

### 10.4 契约柱（场域机制）

场地固定 3 根契约柱，需以**对应属性攻击**充能（各 4s，冰属性最快）。充能完成可任选一种用途：
- （a）净化全场燃烧 / 引力；
- （b）制造一次**强制失衡**（跳过腿甲阶段）；
- （c）为换人反击提供**无敌落点**。

> 契约柱的作用是**降低巨型单位的处理难度方差**：手残玩家可以用「充能 → 强制失衡」换取稳定窗口；高手可以用（c）打出更激进的换人连携。同一机制，两种难度表达。

### 10.5 阶段推进与节奏

| 阶段 | 节奏带 | 玩家行为 | 演出要点 |
|---|---|---|---|
| P1 · 解构腿座 | 对峙 ⇄ 压制（慢，3~4s 一循环） | 在腿间穿梭，打腿甲 / 躲践踏 | 巨像缓慢转身、动作沉重，每次落足全场震屏 |
| P2 · 攀爬与躯干 | 压制 → 终结（中速） | 站上坠落手臂 → 跳上躯干 → 在移动的躯体上战斗 | 躯体即地形：每次挥手改变可站立区域 |
| P3 · 核心与最终 | 终结 → 反转（高压） | 核心暴露 8s，借契约柱净化 | 狂暴：动作加速 15%，牌组更少但更狠 |

### 10.6 演出编排的四个「巨型专属」手法

1. **尺度对比**：攻击后镜头短暂拉远，玩家处于前景；破坏成功时镜头快速推近破坏点。
2. **躯体即地形**：攀爬阶段巨像每次挥手都会改变可站立区域 —— 战斗即平台跳跃。
3. **预兆空间化**：预兆不做在模型上，而做在**地面**（落点标记 / 裂纹扩散 / 光纹旋转），保证任意视角都能读到。
4. **坍塌节拍**：每次部位破坏插入 2.5s 定格 + 1.5s 缓速（我方 AP +35%）+ 6~8s 输出窗口 + 2.0s 复位 —— 它既是爽点，也是玩家重整资源的固定节拍。

## 11. Boss 设计 ③：双 Boss「镜与影 · 双生子」

> 完整图见 `09_boss_duo.png` 与 `12_duo_choreography.png`

### 11.1 定位

双 Boss 的本质是**注意力管理**游戏：玩家不是被难度打败，而是被信息量打败。因此每一条信息都必须可读、可排优先级、可被反制。

| | 镜 · 姊（远程压制） | 影 · 妹（近战突进） |
|---|---|---|
| 定位 | 距离控制与视野压制，不主动近身 | 贴身追猎与确反收割，从视野盲区进入 |
| 威胁 | 镜面投射（复制玩家招式反打）/ 光刃阵列 / 视野遮蔽 | 影步突进 / 背刺投技 / 影分身二段 |
| 破绽 | 施法期间无霸体（但站在影的护卫范围内） | 突进落空后 1.2s 收招硬直（唯一稳定确反点） |
| AI 职责 | 编队中的「压制者」 | 编队中的「收割者」 |

**共享生命池 48,000（两人合计）**：任一方被处决时另一方进入「狂怒」（+20% 增伤）；池归零触发双人谢幕演出（同时处决）。期望 TTK 6~8 min。

### 11.2 编队层状态机

| 阵型 | 触发 | 行为 | 玩家解 | 解算窗口 |
|---|---|---|---|---|
| 压制阵 PRESSURE | 玩家血量 > 60% 且处于对峙带 | 镜持续施法压缩空间，影在外圈游走 | 主动冲向镜（逼影回防）→ 制造分歧 | 镜的施法收招 0.8s |
| 包夹阵 PINCH | 联动度 > 60% 或玩家被击退到墙角 | 影正面压制，镜从背面投射光刃 | 换人开领域 / 反击换人从夹缝穿出 | 影突进落空后 1.2s |
| 交换阵 SWITCH | 任一方体力 < 30% 或被破防 | 两人交叉换位，掩护伤者回气 | 追打破防者 / 远程打断换位 | 换位路径上的 1.5s 交叉点 |
| 合一技 FUSION | 联动度 100%（每 45s 最多一次） | 镜影合一，全屏光阵 + 影刃风暴 | 契约柱净化 / 反击换人 / 地形掩体 | 合击收招后 3s 双人硬直 |

### 11.3 联动度（节奏压力表）

- **上升**：共斗技命中 +15 / 互相掩护 +10 / 玩家被夹击 +8 / 玩家阵亡一位角色 +25
- **下降**：成功打断合击 −30 / 打断交换阵 −20 / 破坏镜面投影 −15 / **单侧连续承伤 −5/s（制造分歧）** / 任一方被处决 −40
- 80% → UI 闪烁 + 音乐升层（合一技进入倒数）；100% → 合一技（每 45s 最多一次）

> 设计红线：联动度只升不「暗中」影响玩家。它必须显示在 UI 上，并可被玩家主动打压。

### 11.4 玩家的「二选一」决策树

| 问题 | 选项 |
|---|---|
| **先杀谁？** | 容错优先 → 先杀影（近战威胁即时）；效率优先 → 先杀镜（破防收益高，但影会狂怒）；节奏优先 → 交替压制，压住联动度再决定 |
| **如何制造分歧？** | 把两人拉开 > 12m（编队层无法触发共斗技）；集火一人时另一人的护卫路径被迫中断；契约柱净化 → 强制打断当前阵型 |
| **何时换人？** | 镜施法期 → 反击换人直接破防镜；影突进落空 → 连携换人接确反连段；合击预兆 → 换人无敌帧规避（唯一无伤解） |
| **失败信号（必须能自己读出来）** | 联动度 ≥ 80% 且两人距离 < 8m → 合一技倒数；两人同时进入攻击前摇 → 包夹阵，必须换人；自己被逼墙角且 AP < 30 → 立即援助换人 |

### 11.5 可读性设计（否则就是无理由的混乱）

1. 前 8 秒内绝不两人同时攻击（编队层的「发言权令牌」）；
2. 两人预兆使用不同色系与音色（镜 = 冷紫 / 镜片声，影 = 暖红 / 布料破空）；
3. 永远只有一人处于「可确反」状态，避免玩家无从选择；
4. 画外音提示另一侧威胁（「小心背后」）+ 0.3s 屏幕边缘方向指示。

### 11.6 常见设计事故与对策

| 事故 | 对策 |
|---|---|
| 两人同时读条 | 发言权令牌：编队层保证同一时刻只有一人处于高威胁前摇 |
| 背后无预兆偷袭 | 画外音 + 屏幕边缘指示；背后攻击的前摇延长 0.3s |
| 无法分辨该打谁 | 优先级信号：濒死轮廓 / 破绽高亮 / 联动度 UI 闪烁 |
| 被打成「两个血包」 | 共享生命池 + 联动度：打一个必然触发另一个的编队反制 |

## 12. 这套系统如何在不同的敌人与玩家之间都成立

> 完整图见 `06_fairness_and_variety.png`

### 12.1 三条不变式（公平性来源）

| 不变式 | 内容 | 违反后果 |
|---|---|---|
| **预兆可视** | 所有威胁在生效前都有视觉 / 音频 / 节奏预兆，且预兆与解一一对应 | 玩家开始怀疑系统，学习曲线断裂 |
| **资源守恒** | 敌我资源都遵循「只能通过行为换回」，不存在无成本回满 | 「读招」失去意义，退化为数值对拼 |
| **脱出权** | 被压制方永远持有至少一条脱出路径（决意脱离 / 换人 / 环境物） | 挫败感无法归因，玩家归咎于设计 |

### 12.2 四个可调旋钮（差异性来源）

每新增一个敌人 = **重新分配这四个旋钮的取值**，而不是新写一套规则：

1. **资源权重**：把破局路径偏向某一资源（反制值型 / 体力型 / 牌组型 / 部位型）；
2. **牌组结构**：单招 / 三连分支 / 读位分支 / 联动合击；
3. **节奏带宽**：慢节奏给 6~10s 读招，快节奏给 3~5s；
4. **空间语法**：柱 / 高低差 / 陷阱 / 可破坏物 —— 决定位移的价值。

### 12.3 敌人谱系（三角定位）

| 原型 | 主破局路径 | 读招重点 | 节奏带偏向 | 作用 |
|---|---|---|---|---|
| 杂兵（3~5 人组） | ① 反制值（一击即破） | 只读「起手方向 + 是否突进」 | 对峙 / 压制 | 节奏素材、回气、清场爽感 |
| 精英（人形 · 有武器） | ① 反制值 ② 牌组读穿 | 分支预兆 | 对峙 / 解算 | 教学关的「格斗对手」 |
| 人形 Boss | ① 牌组 ② 反制值 ③ 体力 | 阶段化牌组 | 五带完整循环 | 博弈教科书 |
| 巨型 Boss | ③ 部位破坏 + ① 躯干反制 | 空间读招 | 对峙 / 终结 | 舞台谜题 |
| 双 Boss | ② 联动度 + 编队读招 | 双线程读招与包夹解算 | 解算 / 反转 | 注意力管理 |
| 无双式清场（可选） | ① 反制值 + 击杀连锁 | 群体预兆与连锁爆发 | 压制 / 终结 | 解压阀（《真三国无双 起源》方向） |

### 12.4 对不同玩家的适配

| 玩家类型 | 系统如何接住他 |
|---|---|
| 动作苦手 | 契约柱 / 环境物 / 援助换人 / 守势型风格 —— 用「场地读招」代替「反应读招」 |
| 动作熟手 | 反击换人 + 牌组读穿 + 压制型风格 —— 用风险换上限 |
| 构筑爱好者 | 武器 × 契约兽 × 风格 = 三重正交组合，且都可改写资源规则 |
| 剧情/演出党 | 演出承担信息功能（预兆、优先级），观感与玩法不打架 |
| 挑战型玩家 | 高难度不加血加伤，而是扩充敌方牌组分支 + 压缩预兆窗口 15% |

## 13. 实现建议（UE5.8 + AURA / GAS）

### 13.1 GAS 映射

| 设计概念 | GAS 实现 |
|---|---|
| 生命 VP / 行动值 AP / 气力 / 韧性 | `AttributeSet`（AP 与气力用 `MetaAttribute` + 恢复 GE） |
| 反制值 / 破绽槽 / 决意条 | `AttributeSet` + `GameplayTag` 门控（仅破绽态可积累） |
| 力竭 / 破防 / 破绽 / 喘息 | `GameplayTag` 状态 + `GameplayEffect` 施加的 debuff |
| 完美格挡窗口 | `GameplayAbility` 的 `ActivationOwnedTags` + 6f 窗口判定（服务端权威） |
| 敌方出招 | `GameplayAbility` + `AbilityTask`（分支选择点用 `WaitForPlayerInput`/条件分支） |
| 节奏表 / AI 选牌 | 独立 `AIControllerComponent`（Utility Scoring），通过 `GameplayTag` 查询状态 |
| 换人 | `GameplayAbility` + `AbilitySet` 切换（进入/退出时授予/移除能力集） |
| 顿帧 / 减速 | `CustomTimeDilation` + `GlobalTimeDilation`（子弹时间） |
| 契约柱 | `Actor` + `GameplayAbility` 交互 + `GameplayEffect` 场域 |

### 13.2 AURA 辅助开发的分工建议

- **可交给 AI 的部分**：Ability 样板代码、AttributeSet 生成、GameplayCue 触发、数据表导入、状态机转移表到代码的机械翻译、调试可视化工具；
- **必须人工把关的部分**：帧数据（前摇 / 有效 / 收招 / 取消窗口）、AI 评分权重、预兆与解的对应关系、演出节奏、难度曲线；
- **建议先做的验证原型（2 周）**：单个精英敌人 + 完整资源条 + 完美格挡与破防 + 一次节奏五带循环。**如果这 2 周里「反击换人」不好玩，整个框架需要重估。**

### 13.3 可拓展空间（留给后续版本）

| 方向 | 拓展方式 |
|---|---|
| 更多武器 | 只改三处参数（完美格挡收益 / 破防技形态 / 收招可取消帧），无需新规则 |
| 更多契约兽 | 每条资源规则可被改写一次 —— 用「规则插槽」而不是「数值堆叠」 |
| 骑乘 / 空战 | 把「高度差」从巨型 Boss 的专属机制提升为通用空间语法 |
| 多人共斗 | 编队层扩展为「玩家编队」，联动度反用于玩家侧（协力技） |
| Roguelike 模式 | 随机化「旋钮取值」+ 房间内节奏带压缩 —— 系统天然支持 |
| PvP（谨慎） | 双方都是玩家时，节奏五带依然成立（对峙 → 抢先手 → 解算），但需要单独的数值平衡 |

### 14.2 上线前自查清单

- [ ] 每个敌招都有唯一预兆，且预兆可被「关掉画面」识别（音效可辨）；
