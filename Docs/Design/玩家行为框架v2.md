# 玩家行为框架 & 资源架构（v2）

> 回应两个问题：**玩家有哪些行为？战技几个？大招怎么做？**
> 以及：**红光/黄光 与 强化攻击 / 非霸体状态 / 指针受损 怎么接进现有系统。**

---

## 第一部分：先解决你指出的那个真问题

你说：

> "如果有大招，大招最好用额外的第三层资源来控制，否则对于同频资源的消耗来讲有点过高，玩家不知道该使用战技/强化重击/强化战技还是大招，而他们都消耗同一种资源。"

**这个判断是对的。** 如果强化重击、强化战技、强化换人、大招**都抢同一条同频**，玩家会陷入"决策瘫痪"——
四个选项、一条资源，算不过来，最后只会选那个数值最高的（通常是刷伤害那个）。

### 解决方案：三层资源，各有各的"币种"

| 层 | 资源 | 回答的问题 | 恢复方式 |
|---|---|---|---|
| **第一层** | **压势指针**（共享） | 这一局谁占上风 | 靠双方行为推动，自动向中点回落 |
| **第二层** | **同频**（个人，100） | 我现在有没有能力做**一个**强化动作 | 命中 +4 / 完美格挡 +12 / 处决 +20 |
| **第三层** | **契约槽**（个人，100） | 我什么时候能放**大招** | **只有强化动作命中才加** |

**关键设计：第三层只能由第二层喂养。**

```
   打普通攻击 ──→ 同频涨（慢）
        │
        ├─ 花 25 同频 ──→ 强化重击命中 ──→ 契约槽 +18
        ├─ 花 40 同频 ──→ 强化战技命中 ──→ 契约槽 +25
        └─ 花 30 同频 ──→ 强化换人命中 ──→ 契约槽 +20 + 压势 +3
                                    │
                                    └──→ 契约槽满 → 放大招（不消耗同频）
```

**这样解决了三件事：**

1. **不再抢同一条资源**：大招花的是契约槽，不是同频。玩家不需要在"强化重击还是大招"之间算账。
2. **契约槽告诉你"你打得对不对"**：只有强化动作命中才攒。如果你一直在打普通攻击，大招永远是空的 —— 它在**逼你用强化动作**，也就是逼你从"按键流水线"升级成"有意识投资"。
3. **失败不惩罚**：强化动作打空了就不加契约槽。你不用怕"浪费了大招"。

### 一个附加的甜点：契约槽满时，同频获得被动

契约槽满的瞬间，给一个持续加成（比如**所有同频消耗 −20%**，直到你放大招）。
这样"攒满但还没放"本身就是一个有收益的状态，玩家会愿意**等一个好时机放大招**，而不是攒满立刻按掉。

### 备选方案（如果你想更简洁）

把大招做成**同频的溢出释放**：同频满 100 时才能放，放完清空。
- 优点：只有两条资源，极简
- 缺点：同频同时管小动作和大招，又会回到你担心的"决策瘫痪"

**我推荐三层方案。** 多一条槽，但每条槽的问题都很清楚。

## 第二部分：玩家的完整行为清单

分四类：**基础动作 / 强化动作 / 换人 / 大招**。
（强化 = 消耗同频，附带【破红】能力）

### 一、基础动作（不消耗同频）

| # | 行为 | 输入 | 作用 | 备注 |
|---|---|---|---|---|
| 1 | **轻攻击** | 轻 | 连段起手、攒同频（+4/次） | 3 段，第 3 段有位移 |
| 2 | **轻→轻→重 派生** | 轻轻重 | 收尾击退，破轻霸体 | 最常用的收招 |
| 3 | **轻→重 派生** | 轻重 | 上挑，把敌人浮空 | 起手 22 帧，可接追击 |
| 4 | **方向派生（前）** | 前 + 重 | 突进斩，缩短距离 | 追击用 |
| 5 | **方向派生（后）** | 后 + 重 | 后撤斩，边退边打 | 危险时保命 |
| 6 | **方向派生（左/右）** | 左/右 + 重 | 横扫，扫到侧面 | 打多个敌人 |
| 7 | **延迟重击** | 轻后停顿再按重 | 变招，与"轻重"动作不同 | 骗敌人反击 |
| 8 | **重击** | 重 | 高伤害、破轻霸体 | 前摇 22 帧 |
| 9 | **蓄力重击** | 长按重 | 破重霸体 | 前摇 40 帧，风险大 |
| 10 | **闪避** | 回避键 | 无敌 11 帧 | 耗同频 12 |
| 11 | **跳跃 / 下劈** | 跳跃 + 攻击 | 躲下段（黄光） | 3C 行为 |
| 12 | **格挡** | 格挡键 | 减伤 70% | 每段耗同频 8 |
| 13 | **完美格挡** | 命中前 6 帧格挡 | 完全免伤 | **同频 +12、压势 +2** |
| 14 | **普通投技 / 挣脱** | 近身 + 特殊键 | 破敌人格挡 | 敌人也会用，需要挣脱 |

### 二、强化动作（消耗同频，全部具备【破红】能力）

> **共同规则：起始 8 帧内带霸体**（类似忍龙 4 的强化攻击），所以"看到红光立刻按"是成立的。
> 命中后：**契约槽增加 + 压势推进 + 延长敌人的非霸体状态**。

| # | 行为 | 同频消耗 | 契约槽 | 特点 |
|---|---|---|---|---|
| 15 | **强化重击** | −25 | +18 | 单发、高伤害、破霸体。最基础的投资 |
| 16 | **强化战技 A（伤害型）** | −40 | +25 | 单点爆发，适合收尾 |
| 17 | **强化战技 B（控制型）** | −40 | +22 | 击倒 / 定身，创造输出窗口 |
| 18 | **强化战技 C（位移型）** | −35 | +20 | 带位移，用来贴脸或脱离 |
| 19 | **强化战技 D（范围型）** | −45 | +20 | 清小怪或被围时解围 |
| 20 | **强化换人 · 续奏** | −30 | +20 | 连段不断，换人同时破红 |
| 21 | **强化换人 · 接管** | −50 | +30 | 慢动作 + 无敌 + 反击，压势 +4 |
| 22 | **强化处决** | −30 | +15 | 断链时追加伤害（可选） |

**战技数量：每把武器 4 个（伤害 / 控制 / 位移 / 范围），3 把武器 = 12 个。**

### 三、换人（详见第四部分）

| # | 行为 | 同频 | 特点 |
|---|---|---|---|
| 23 | 普通续奏换人 | 0 | 连段接续，无破红 |
| 24 | 普通接管换人 | 0 | 敌方起手时按，无敌闪避，无破红 |
| 25 | 代奏（援助） | 0 | 队友出场放一个技能即退，CD 25s |
| 26 | **强化续奏 / 强化接管** | −30 / −50 | **具备破红**，见上表 |

### 四、大招（契约槽满时可用，不消耗同频）

| # | 行为 | 消耗 | 特点 |
|---|---|---|---|
| 27 | **契约共鸣（大招）** | 契约槽 100 | 全屏 / 大范围，命中后压势 **+15**，直接推到接近端点 |
| 28 | **变身 / 残响具现**（可选） | 契约槽 100 | 不造成伤害，而是 8 秒内**所有强化动作免同频** |

> 两种大招形态给玩家选：**要一次性的大收益，还是要一段时间的自由度**。
> 这本身就是个有趣的决策，而且只有一条资源，不会决策瘫痪。

## 第三部分：红光 / 黄光 —— 你的提案我完全采纳，并补全了细节

### 为什么这个设计好

| | 红光 | 黄光 |
|---|---|---|
| **考什么** | **考资源**（同频够不够） | **考操作**（3C 用得好不好） |
| **怎么解** | 强化动作破掉 / 或者跑远 | 闪避 / 跳跃 / 换人无敌 |
| **解掉的收益** | **敌人超长硬直，你打一套** | **压势推进**（它空招了） |
| **没解掉的代价** | 巨量伤害 | 巨量伤害 **+ 压势指针受损加重** |
| **失败后还有机会吗** | **有**：非霸体白覆层 3 秒 | 没有补偿，但也不额外惩罚 |

**这个不对称非常好**，因为：
- 动作苦手 → 红光是"跑远"就能处理，黄光练好闪避就行
- 动作熟手 → 红光用强化动作破，把"资源"变成"机会"
- 两种人都有活路，但**上限不同**

### 红光（不可防御）—— 完整规则

```
敌人亮红光（蓄力征兆：低频音 + 武器泛红 + 身体后坐）
   │
   ├─ 选项 1：强化动作破红 ── 起始 8 帧霸体 → 命中即破
   │         └─ 收益：敌人超长硬直 2.5 秒 → 你打一整套 + 契约槽
   │         └─ 代价：同频 25~50
   │
   ├─ 选项 2：远离 / 位移脱离攻击范围
   │         └─ 收益：不掉血
   │         └─ 代价：什么都不赚，而且如果没跑出去就是巨量伤害
   │
   └─ 选项 3：硬吃
             └─ 巨量伤害（约 30% 最大生命）+ 压势大幅倒退
```

**红光被破 → 敌人超长硬直（2.5 秒）。** 这是你唯一能打出"完整一套"的窗口。

**红光释放完毕（你没破它）→ 敌人进入【非霸体状态】，身上覆一层白，持续 3 秒。**
这 3 秒里，**任何攻击都能打断它**。

### 【非霸体状态】的延长机制 —— 这是你提的最妙的一条

> 玩家可以通过消耗同频的【强化攻击】来延长白覆层的时间，每个强化动作加不同的时间，最高到 10 秒。

**我把这条做成一张明确的表：**

| 你在这 3 秒内做的事 | 白覆层剩余时间变化 |
|---|---|
| 什么都不做 | 3 秒后消失，敌人恢复霸体 |
| 轻攻击命中 | **−0.5 秒**（普通攻击会**缩短**它）|
| 强化重击命中 | **+1.5 秒** |
| 强化战技命中 | **+2.5 秒** |
| 强化换人命中 | **+2.0 秒** |
| 上限 | **10 秒**（到顶后不再延长）|

**为什么"普通攻击缩短它"这个细节很关键：**
它把白覆层变成一场**资源考试** —— 你不能用它来无脑刷伤害，你必须**持续投资强化动作**才能维持窗口。
手里同频不够 → 窗口会自己关掉。这让"攒同频"这件事有了一个极其明确的用途。

**这会自然产生一个高潮段落**：
红光 → 强化破 → 打一套 → 敌人起身放红光 → 你再破 → 白覆层一路延长到 10 秒 → 一套打掉 25% 血。
**这是玩家会截图发论坛的时刻。**

### 黄光（投技 / 下段）—— 完整规则

```
敌人亮黄光（征兆：身体压低 + 音效上扬 + 手部张开）
   │
   ├─ 最优解：闪避（无敌帧）/ 跳跃（下段）/ 换人（无敌）
   │         └─ 收益：它空招 → 压势 +3 → 你拿到确反窗口
   │
   └─ 失败：被抓住 / 被打倒
             └─ 巨量伤害 + 【压势指针受损加重】15 秒
```

**你提的「压势指针受损程度上升」我理解成这个意思（如果不对告诉我）：**

> 黄光攻击**释放完成**后（不管有没有打到你），接下来 **15 秒内**：
> - 你每被打中一次，指针损失的格数**翻倍**（−2 → −4）
> - 它的攻击推力**减半**（你的 +1 → +0.5）
> - 也就是：**这一段时间你处于"理亏"状态，必须打得更保守**

**这样黄光就有了一个长尾后果**，而不只是"扣血"。玩家会记住："刚才那个投技没躲掉，接下来 15 秒我都得小心。"

**另一种可能的理解（也可以两个都做）：**
> 黄光释放后，如果被它命中，**指针直接朝敌人方向跳 8 格**（而不是常规的 −2）。

### 补全：两种信号的完整对照

| | 🔴 红光 | 🟡 黄光 |
|---|---|---|
| **能不能防** | 不能（格挡 / 完美格挡都无效） | 不能 |
| **能躲吗** | 能，但范围大 / 段数多，躲开需要提前动 | 能，闪避 / 跳跃 / 换人无敌，是**最优解** |
| **有 3 种解吗** | ✅ 强化动作 / 跑远 / 硬吃 | ✅ 闪避 / 跳跃 / 换人 |
| **破掉它的收益** | **超长硬直 2.5 秒** → 打一整套 | 它空招 → 压势 +3 → 确反窗口 |
| **没破掉的收益** | **白覆层 3 秒（可延长到 10 秒）** | 压势受损加重 15 秒 |
| **为什么这样设计** | 让"资源多的人"有额外选项 | 让"操作好的人"有额外选项 |
| **占比建议** | 敌人招式的 15~20% | 10~15% |

> **注意最后一行**：两种特殊攻击加起来只占 25~35%，剩下 65~75% 是普通攻击。
> 这个比例很重要 —— 特殊攻击太多会变成"天天在解谜"，太少又感觉不到存在。

## 第四部分：换人怎么嵌进这套系统（你提的方向）

你说"换人机制与出场技要和这套系统嵌合"。我的方案：

### 换人有三种"身份"

| 身份 | 什么时候用 | 作用 |
|---|---|---|
| **节奏工具**（原设计） | 连段中 / 被压制时 | 换节奏带，重置主动权 |
| **防御手段**（新增） | 黄光来袭时 | **换人无敌帧 = 躲黄光的三种解之一** |
| **破红手段**（新增） | 红光来袭时 | **强化换人 = 破红的手段之一，而且是最快的那种** |

### 具体的输入设计

```
换人键 + 普通按    → 续奏换人（连段接续，无破红）
换人键 + 敌人起手时 → 接管换人（无敌闪避，无破红）—— 可躲黄光
强化键 + 换人键    → 强化续奏 / 强化接管（耗同频 30 / 50）
                     ★ 起始 8 帧霸体 → 可破红光，且比强化重击快 3 帧
```

**为什么强化换人要比其他强化动作快 3 帧？**
因为它是**最贵**的（30~50 同频），应该给一个"手感上的奖励"。
玩家会形成肌肉记忆："看到红光，第一反应是按强化+换人"—— 这个操作**帅**，而且它是**三人队伍系统独有的**，
别的游戏抄不走。这是我们的差异化。

### 三人队伍的差异化在破红上的体现

每个角色的**强化换人出场技**不同：

| 角色 | 强化出场技 | 破红特点 |
|---|---|---|
| 疾风 | 突进穿刺 | **最快**（快 5 帧），但范围小 |
| 磐石 | 震地斩 | 最慢，但**范围大**，能破多段红光 |
| 炽 | 双刃旋斩 | 中等，但**破红后额外延长白覆层 +1 秒** |

**这就给了"换谁上场破红"一个真实的策略维度。**

## 第五部分：完整资源架构图（文字版）

```
┌─────────────────────────────────────────────────────────────┐
│  第一层 · 压势指针（共享，双方在拔河）                          │
│  推法：强化动作 +3~+4 / 完美格挡 +2 / 处决 +5 / 成功躲黄光 +3    │
│  防守：被打 −2 / 黄光后 15 秒内损失翻倍                         │
│  归零/满 → 一方跪下，另一方获得处决权                            │
└─────────────────────────────────────────────────────────────┘
              ↑ 推进                    ↓ 决定
┌─────────────────────────────────────────────────────────────┐
│  第二层 · 同频（个人，100）                                    │
│  回充：命中 +4 / 完美格挡 +12 / 处决 +20                       │
│  消耗：闪避 −12 · 格挡每段 −8 · 强化重击 −25 · 强化战技 −35~45   │
│        · 强化换人 −30~50 · 白覆层延长（等于持续消耗）            │
│  归零 → 虚弱 3 秒                                             │
└─────────────────────────────────────────────────────────────┘
              ↓ 强化动作命中时喂养
┌─────────────────────────────────────────────────────────────┐
│  第三层 · 契约槽（个人，100）                                  │
│  唯一来源：强化动作命中（+15 ~ +30）                            │
│  满 → 放大招（契约共鸣 / 变身），不消耗同频                      │
│  满而未放时：同频消耗 −20%（鼓励等好时机）                       │
└─────────────────────────────────────────────────────────────┘
```

**一句话教学：**

> **普通攻击攒同频，同频喂强化动作，强化动作推压势、攒契约，契约满了放大招。**
> **看到红光按强化，看到黄光按闪避。**
