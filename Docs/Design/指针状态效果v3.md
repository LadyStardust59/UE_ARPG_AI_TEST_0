# 隐形加法 · 指针状态效果（v3 补丁）

> 回应两个新想法：
> ① 【白光非霸体】改成隐藏累积值，多入口触发
> ② 指针【领先 / 落后】状态下加通用效果（类似大乱斗百分比）
>
> **这份文档只写新增的部分。已有规则不变。**

---

## 第一部分：先解决你担心的那个冲突

你问：

> "敌人领先则一直维持霸体（只有敌人处于指针落后时才出白光）？但这样是不是和红光有点冲突？"

**是的会冲突，而且冲突点很具体：**

> 红光被破 → 敌人超长硬直 → 之后必然出现白光窗口。
> 但按"落后才出白光"的规则，如果敌人**领先**，红光被破后就不该有白光 —— 那红光破防的收益就没了。

### 解决办法：把「触发」和「加速」分开

| | 白光什么时候出现 | 受指针位置影响吗 |
|---|---|---|
| **触发条件** | 两个入口（见下） | **完全不影响** |
| **累积速度** | — | **影响：落后时累积更快** |

**所以指针位置不决定"能不能出白光"，只决定"多快能出白光"。** 冲突消失。

而且这个设计**对落后方更有利**：
- 你落后（敌人领先）→ 敌人**更容易被打破绽** → 这是你的翻盘机会
- 敌人落后（你领先）→ 它**更难被打破绽**，但它攻势更猛 → 它靠伤害翻盘

**两条翻盘路径，不一样。这就是好设计。**

## 第二部分：白光非霸体 —— 改成隐藏累积值

### 核心改动

原来：只有"红光释放完毕"才能进白光。

现在：**一个隐藏值，打空进白光。**

### 隐藏值「硬直累积」

| 项 | 数值 | 说明 |
|---|---|---|
| 名称（内部） | StaggerBuildup | **不显示给玩家** |
| 单位 | 点（满 100） | |
| **受击累积** | **每命中 +6** | 轻击重击一样，看次数不看伤害 |
| **完美格挡累积** | **每次 +12** | 格挡也算"打中"了它的节奏 |
| **无受击恢复** | **连续 4 秒没被打中后，每秒 −10** | 逼你保持压力 |
| 打空 | → 进入**白光非霸体 3 秒** | |
| 冷却 | 每次触发后 **20 秒内不再累积** | 防止刷破绽 |
| 每阶段上限 | **最多触发 2 次** | 防止 BOSS 战变成打木桩 |

> **数值感觉**：全部用完美格挡 → 9 次；全部用轻击 → 17 连击；混合 → 12~14 次。
> 4 秒不打扰就回 10/秒，所以你必须**连续施压**，中间断了就白打。

### 白光的三个入口（**互不排斥，可以都在**）

| 入口 | 触发方式 | 特点 |
|---|---|---|
| **入口 A · 打空累积值** | 连续命中 / 完美格挡把它打空 | **你需要主动进攻才能刷出来** —— 奖励压制型打法 |
| **入口 B · 红光被破** | 用强化动作破掉红光 | 固定给**超长硬直 2.5 秒 + 白光 3 秒** |
| **入口 C · 完美格挡累计** | 完美格挡累计 2 次 | 门槛更低，但窗口更短（1.5 秒） |

**三个入口对应三种玩法：**
- 只会猛攻 → 靠入口 A
- 会读红光 → 靠入口 B
- 只会精准防御 → 靠入口 C

**每种玩家都能靠自己擅长的方式打出破绽。这是"人人有活路"。**

### 指针位置怎么影响它

| 指针位置 | 累积速度 |
|---|---|
| 你**领先** | **×0.7**（敌人变"硬"，难打崩 —— 它靠伤害翻盘） |
| 对峙 | ×1.0 |
| 你**落后** | **×1.3**（敌人变"脆"，好打崩 —— 这是你的翻盘机会） |
| 你**大落后** | **×1.6** |

> 所以：**领先的时候你更容易赢在伤害，落后的时候你更容易赢在破绽。**
> 两条路都通向胜利，但走的不是同一条路。

## 第三部分：指针的六段区（大乱斗百分比思路）

指针满程 100，中点 50。分成六段，每段有自己的通用效果。

```
 敌大领先      敌领先    对峙    你领先      你大领先
 ├────────┼────────┼────────┼────────┼────────┤
 0~15     15~35    35~65    65~85    85~100
```

### 效果表（这是新增的全部内容）

| 指针位置 | 推**力**倍率 | 同频回充 | 白光累积 | 伤害系数 | 特殊 |
|---|---|---|---|---|---|
| **你大领先**（85~100） | **×1.35** | **+30%** | ×0.7 | 你 ×1.00 / 敌 ×1.25 | 敌人挣扎 |
| **你领先**（65~85） | ×1.15 | **+15%** | ×0.7 | 你 ×1.00 / 敌 ×1.15 | — |
| **对峙**（35~65） | ×1.00 | 基准 | ×1.0 | 双方 ×1.00 | — |
| **你落后**（15~35） | **×1.15** | **−15%** | ×1.3 | 你 ×1.15 / 敌 ×1.00 | 你挣扎 |
| **你大落后**（0~15） | **×1.35** | **−30%** | ×1.6 | 你 ×1.25 / 敌 ×1.00 | 你挣扎 |
| **端点** | — | — | — | — | 一方跪下，另一方处决权 |

### 三条设计原则

**① 落后方的攻击推得更远（核心的翻盘机制）**
你落后 → 你的每次攻击推动指针的倍率 ×1.15~×1.35。
**所以"落后"不代表劣势固定，它反而给了你更快的翻盘速度。** 这就是大乱斗的百分比思路。

**② 落后方伤害更高，但也更脆**
你落后 → 你造成伤害 ×1.15~1.25。**同时**敌人被打破绽的概率上升（白光累积 ×1.3~1.6）。
所以落后时你既打得更疼，也更容易找到破绽 —— **但你的同频回充更慢**，所以你的强化动作更少。
**"我更强了，但我做不了强化动作"** —— 这是很妙的张力。

**③ 领先方靠资源优势，而不是靠伤害**
领先 → 同频回充 +15~30%。你可以更频繁地用强化动作。
但你的推力倍率也是 ×1.15~1.35 —— 所以你领先时更容易**扩大**优势。
**这就是滚雪球，所以需要一个闸门（见下）。**

### 防滚雪的闸门

大乱斗的百分比之所以不会滚雪球失控，是因为领先方自己也变脆。我们照抄这个逻辑：

| 闸门 | 规则 |
|---|---|
| **闸门 1 · 领先方也变脆** | 你领先时，**敌人对你的伤害 ×1.15~1.25** —— 领先不等于安全 |
| **闸门 2 · 端点重置** | 推到端点结算后，指针**重置到 60/40**（不是 50/50），给推方一点保留优势，但不给满 |
| **闸门 3 · 大领先时回充封顶** | 你大领先时，同频回充的上限被压到 70（不能攒满反复打强化） |

## 第四部分：UI 怎么呈现（隐形加法的可见化）

隐形不等于玩家不知道。**玩家必须能感觉到"我现在处于什么段位"。**

```
┌──────────────────────────────────────────────────────────┐
│  敌大领先 ←────────●──────────────────────→ 你大领先      │
│                  ↑                                       │
│            [ 你落后 · 攻势 ×1.15 · 同频回充 −15% ]         │
└──────────────────────────────────────────────────────────┘
```

- 指针下方**一行小字**，实时显示你当前的段位效果
- 段位变化时**指针颜色渐变**（不用闪烁，免得像信号灯）
- **不显示具体数字倍率** —— 只显示"攻势上升 / 同频下降"这样的方向词

> **为什么用方向词而不是数字**：
> 显示 `×1.15` 会让玩家开始算数学，那就变成了数值游戏。
> 显示"攻势上升"会让玩家凭感觉打 —— 这才是动作游戏。

## 第五部分：汇总 —— 这一版新增了什么

| 项 | 内容 |
|---|---|
| **新增机制 1** | 隐藏值「硬直累积」：受击 +6 / 完美格挡 +12 / 4 秒不被打 −10/s，打空 → 白光 |
| **新增机制 2** | 白光的**三个入口**（打空累积 / 红光被破 / 完美格挡 ×2） |
| **新增机制 3** | 指针六段区，每段有推力倍率 / 同频回充 / 白光累积 / 伤害系数的修正 |
| **新增机制 4** | 落后方推力与伤害加成（大乱斗百分比思路）+ 三道防滚雪闸门 |
| **修改** | 白光触发**不再依赖红光**；指针位置只影响累积速度，不影响能否触发 |
| **保持不变** | 三层资源、27 个动作、红黄光的三种解、白覆层的延长规则 |
