# 资源简化说明（v1.1）

> **这份文档是对《战斗系统设计文档》的修订。**
> 原文档不动，本文件记录改了什么、为什么改。两处冲突时，**以本文件为准**。
>
> 起因：策划反馈"资源有点多、有点复杂臃肿"。这是对的 —— 第一版把每一条能想到的
> 张力都做成了一个独立资源，结果玩家要同时看 15 条槽。

---

## 一、简化原则

**一条资源只有在「玩家能感觉到它、并且会因为它改变打法」时才保留。**

用这三条筛：

| 筛子 | 问题 | 淘汰了什么 |
|---|---|---|
| 感知性 | 玩家会不会在战斗中主动去看它？ | 处决槽（魂隙只有 2~4 秒，没人会看第四条槽） |
| 决策性 | 它会不会让你改变这一招怎么打？ | 韧性槽（被破防只是挫败，不产生新决策） |
| 唯一性 | 它是不是另一条资源的重复？ | 共鸣槽（与契约槽功能完全相同） |

---

## 二、砍掉 / 合并清单

### 删除（4 条）

| 原资源 | 删除理由 | 替代方案 |
|---|---|---|
| **韧性槽**（玩家） | 被破防的挫败感全来自它 —— 而它并不产生新的决策 | 改成「连段被打断」：失去的是节奏，不是一个槽 |
| **处决槽** | 魂隙只有 2~4 秒，玩家不会去看第四条槽 | 魂隙窗口内**直接可断链**，不需要第二层积累 |
| **共鸣槽**（全队） | 与契约槽完全重复：都是「攒满放大招」 | 合并进**契约槽**，保留"全队共享"这个唯一特性 |
| **霸体三级** | 三级与两级在玩家体感上没有区别 | 简化为「**傀化**：有 / 无」两级 |

### 合并（2 组）

| 原资源 | 合并为 | 理由 |
|---|---|---|
| 行动值 AP + 韧性 | **身法** | 两者本质都是"我还能不能动"；一条槽同时表达位移燃料与被打断的代价 |
| 破绽槽 + 处决流程 | **魂隙 → 断链** | 两段式（积累→处决）不如一段式（破绽即可处决）干脆 |

### 保留（6 条）—— 这是最终的全部资源

| 归属 | 资源 | 上限 / 基线 | 为什么必须留 |
|---|---|---|---|
| 玩家 | **身法** | 100（静止 +9/s） | 位移与破防的燃料；归零 → 脱力。它是"被压制有代价"的载体 |
| 玩家 | **气力** | 100（只有进攻才回） | 它让"主动进攻"在数值上优于"龟缩防守"—— 这是中速博弈的发动机 |
| 玩家 | **契约槽** | 100（全队共享） | 唯一一条**全队共享**的资源，换人与断链都要加它，所以产生"谁来放"的决策 |
| 敌人 | **意志** | 杂兵 60 / 人形 600 / 巨躯 1200 | 破局路径①的载体：打满 → 魂隙 → 断链 |
| 敌人 | **耐性** | 100（出招即消耗） | 破局路径②的载体：耗尽 → 脱力 → 确反。它让"骗招"成为一种打法 |
| 敌人 | **傀化** | 有 / 无 | 回答"这一招能不能打断它"—— 一个按钮级的信息 |

**玩家 3 条 + 敌人 3 条，一一对应**，这是刻意的：玩家看自己的三条，就能推断敌人的三条。

## 三、需要同步修改的数值

以下数值在原设计文档里需要替换：

| 位置 | 原值 | 新值 |
|---|---|---|
| 玩家资源列表 | 生命/AP/气力/韧性/破绽/决意/情绪/大招/共鸣（9 条） | 生命 / 身法 / 气力 / 契约槽（+战斗外资源） |
| AP 上限 | 未定义 | **身法上限 100** |
| 韧性 | 100 | **删除** |
| 破绽槽 | 100 | **删除**（改为魂隙直接可断链） |
| 共鸣槽 | 100 | **删除**（并入契约槽） |
| 敌方霸体 | 无 / 轻 / 重（三级） | **傀化：有 / 无（两级）** |
| 处决伤害 | 8~12% 最大生命 | 不变 |
| 反制值 | 60 / 600 / 1200 | 同值，但改名为**意志** |

> 决意条（0~3）保留 —— 它是"被压制方的脱出权"，属于设计红线，不能砍。
> 建议改名为「**执念**」（见《包装方案与世界观》）。

## 四、简化前后对比

| | 简化前 | 简化后 |
|---|---|---|
| 战斗中需要关注的槽 | **15 条** | **6 条** |
| 玩家侧 | 9 条（生命/AP/气力/韧性/破绽/决意/情绪/大招/共鸣） | 4 条（生命/身法/气力/契约槽） |
| 敌方侧 | 6 条（生命/部位/反制值/体力/霸体三级/节奏表） | 4 条（生命/意志/耐性/傀化） |
| 玩家每次交锋要做的判断 | 约 5 个 | **2 个**（征兆是哪种 → 选哪一种解） |
| 破局路径 | 3 条（其中一条是"知识"不算资源） | **3 条不变** |
| 核心玩法是否改变 | — | **完全没有改变** |

**关键结论：简化的是"玩家要看的东西"，不是"系统能做的事"。**
三条破局路径、四选一决策、主动权轴、节奏五带，全部原样保留。

## 五、给美术 / UI 的改动清单

| 项 | 改动 |
|---|---|
| 玩家 HUD | 从 9 条减到 4 条：生命（粗）、身法（青）、气力（金）、契约槽（紫，全队共享） |
| 敌人 HUD | 生命条 + 意志（黄）+ 耐性（细白）+ 傀化（轮廓光泽，不做成条） |
| 裁决提示 | "傀化：有" 时不显示"可打断"提示；"无"时显示 |
| 教程 | 教学只需讲 4 个槽 + 2 个判断（原来是 9 个槽） |
| 魂隙表现 | 不需要额外的槽，改为敌人跪下 + 轮廓开裂 + 断链提示 |
