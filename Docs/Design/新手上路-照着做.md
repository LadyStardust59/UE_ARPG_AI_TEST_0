## 第一部分：三句话讲清楚原理

**第一句：AURA 是个很听话但很笨的施工队。**
你说"给我盖个房子"，它会瞎盖。你说"在 A 点盖一个 3 米宽、2 米高、朝南的门"，它盖得又快又好。

**第二句：所以我们的活儿，就是把它要的东西写清楚。**
它需要知道：**放哪儿、叫什么名、多大、什么颜色、做完了怎么算成功。**
这五件事写在纸上，就是所谓的"契约"。别被这个词吓到 —— 它就是一张**购物清单**。

**第三句：一次只让它做一件小事，做完立刻试。**
就像玩乐高：不能把整盒倒出来。先拼一块，按上去试试牢不牢，再拼下一块。
一次让它做十件事，出了问题你根本不知道是哪件坏了。

> **唯一要记住的规矩**：一个数字（比如"格挡窗口 6 帧"）**只能写在一个地方**。
> 写两遍，两个地方就会慢慢变得不一样，最后没人知道哪个是对的。

## 第三部分：开工前，花 10 分钟做两件事

### ① 在 UE 里建这几个文件夹

在内容浏览器里，右键 → 新建文件夹，照着建（名字**必须一模一样**，大小写也别改）：

```
Content/
├─ Combat/          ← 战斗相关的东西都放这里
│  ├─ Abilities/    ← 招式、格挡这些"动作"
│  ├─ Data/         ← 数字表格
│  ├─ Characters/   ← 角色
│  └─ FX/           ← 特效音效
├─ AI/              ← 敌人的脑子
├─ Levels/          ← 关卡
└─ Art/             ← 模型、材质（先用引擎自带的）
```

【要给我看的证据】

## M2 · 格挡 + 完美格挡（最重要的一步）

> 这是整个战斗系统的**心脏**。格挡手感不对，后面全白做。

### 你要对 AURA 说的话

```
【这一轮只做一件事】
给 AAM_CombatCharacter 加格挡能力，包含"普通格挡"和"完美格挡"两种情况。
不做别的。

【沿用上一轮的成果】
角色、属性表、行动值都继续用，数字仍然统一放在 DT_CombatNumbers 里。

【项目情况】
- 引擎 UE5.8，GAS 已启用
- 上一轮已经有了：生命值、行动值、轻击、重击、翻滚
- 全部继续用蓝图，不要写 C++

【要做的内容】
按住一个键（默认鼠标侧键或 Q）就是举盾格挡：
  - 举着的时候，受到伤害减少 70%
  - 每挡住一次攻击，扣 8 点行动值
  - 行动值不够 8 点的时候，格挡会失效，并且进入"力竭"状态 3 秒
    （力竭时：移动速度降到 65%，不能翻滚，受到的伤害增加 25%）

关键部分 —— 完美格挡：
  - 在敌人攻击"刚要打到你"的那 6 帧内按下格挡，算完美格挡
  - 完美格挡时：完全免伤，敌人硬直 0.4 秒，并且敌人会"踉跄"
  - 完美格挡后 12 帧内你的下一击伤害翻倍（这就是"反打"）
  - 如果没打出完美格挡，就是普通格挡（减伤 70%）

表现（先用最简的）：
  - 普通格挡：角色变蓝 0.1 秒
  - 完美格挡：角色变白 0.15 秒 + 一个白色圆环特效

【硬性限制】
- "6 帧"这个数字只允许出现在 DT_CombatNumbers 里，别的地方一律引用它
- 不要改上一轮已经做好的轻击、重击、翻滚
- 判定必须在服务器端做（如果你知道怎么做的话；不确定就先做单机版并告诉我）

【做完的标准】
1. 编译/保存后没有任何报错
2. 自动化测试要包含：
   - 正好在第 6 帧按下格挡 → 判定为完美格挡
   - 第 7 帧才按下 → 判定为普通格挡
   - 行动值不足时格挡 → 进入力竭，3 秒后自动恢复
   - 完美格挡后 12 帧内的攻击，伤害确实是 2 倍
3. 格挡窗口实测：做 20 次测试，把每次的帧数发我

【要给我看的证据】
1. 新建资产清单
2. 自动化测试结果
3. 20 次窗口测量的原始数据
4. 一段 20 秒的录屏（或几张截图），让我看到普通格挡和完美格挡长什么样
5. 用搜索功能确认一下：代码/蓝图里搜 "6" 或 "0.4"，看是不是只在数据表里出现过

【卡住了怎么办】
如果不确定"6 帧窗口"该怎么实现，或者 GAS 里做服务器判定有困难，
把问题列出来停下来问我。不要用"大概差不多"的方式糊过去。
```

### 做完你自己试这五件事（最重要的一次试玩）

1. **乱按格挡**，能不能挡住？（应该能，减伤 70%）
2. **看准了按**，有没有"啪"一下弹开敌人的感觉？（这就是完美格挡）
3. 弹开之后**立刻反打**，伤害是不是明显更高？
4. 一直按着格挡不放，**行动值会不会掉光**？掉光之后是不是很难受？
5. **格挡手感是"提前按"还是"刚好按"？** —— 如果必须提前按才有用，说明窗口判定错了，告诉我。

> **这一步的手感，决定了整个游戏好不好玩。** 不要急着往下走，试到你觉得"爽"为止。

1. 新建资产清单
2. 自动化测试结果
3. 会心值从 0 涨到满、再清零的完整过程记录
4. 木桩三种状态各一张截图

【卡住了怎么办】
如果你觉得"破绽期间伤害翻倍"和其他系统有冲突，先说清楚冲突在哪，

   - 反击换人按失败 → 两个角色都掉血，且伤害是 1.5 倍
   - 冷却期间按换人键 → 没有任何反应（并且界面上能看出来）

【要给我看的证据】
1. 新建资产清单
2. 自动化测试结果

【卡住了怎么办】
"时间变慢"如果这一轮做不出来，先跳过，跟我说一声，我们后面补。

## 第五部分：三条救命规则

**规则 1：一次只做一件事。**
