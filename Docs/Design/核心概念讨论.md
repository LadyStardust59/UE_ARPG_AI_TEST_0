# 核心概念讨论 & 资源合并方案

> 这份文档是**提案，不是结论**。三项里前两项我建议直接定，第三项想听你意见。

---

## 问题的诊断

现在这套系统缺什么？缺一个「一句话就能说清、而且贯穿每一秒」的东西。

| 游戏 | 核心概念 | 一句话 |
|---|---|---|
| 只狼 | 躯干条 | 不用打死他，打崩他的架势 |
| 仁王 | 架势 + 残心 | 切换姿态换攻防属性，打完要收招回气 |
| 鬼武者 | 一闪 | 在敌人命中前一瞬按下，直接秒杀 |
| 卧龙 | 化解 | 化解攻击转化成士气 |
| 街霸 6 | 斗气槽 | 一条槽同时管进攻、防守、反击，用光就虚弱 |

而我们现在是：**四选一 + 破绽值 + 体力 + 三条破局路径**。每一条单独看都对，但没有一个"母题"把它们串起来。玩家打完一场，说不出"这游戏的核心是 XX"。

## 提案一：核心概念 = 「一条公开的压力条，双方在拔河」

### 这个概念是什么

屏幕上**只有一条**贯穿全场的横条。它不属于你，也不属于敌人 —— 它是**你们俩之间那条线的位置**。

```
敌人崩 ←———————————————————●———————————————————→ 你压制
                       ↑
                现在谁占上风
```

**你的每一个动作，都在推这根指针：**

| 你做的事 | 指针 | 为什么这样设计 |
|---|---|---|
| 轻击命中 | **+1 往你** | 进攻是最基本的推力 |
| 重击 / 破防技命中 | **+3 ~ +4 往你** | 高承诺动作给高推力 |
| 完美格挡 | **+2 往你** | 防守成功也是进攻 |
| 处决（破绽窗口） | **+5 往你** | 兑现优势 |
| 被打中 | **−2 往敌人** | 失误要有代价 |
| 普通格挡 | **0** | 挡住只是不亏，不赚 |
| 闪避 | **0**，但消耗资源 | 位置优势不是资源优势 |
| 什么都不做 | 每秒**向中间回落 1** | **龟缩不能赢** —— 这是最重要的一条 |

**推到两端的后果：**

| 指针到端点 | 发生什么 |
|---|---|
| **推到敌人一侧** | 它「魂隙」—— 跪下 2~4 秒，**你获得一次处决权**，然后指针重置回中间偏你一点 |
| **推到你这一侧** | 你「脱力」—— 定力被击穿，**当前动作被打断，1.5 秒不能做高承诺动作**，指针重置回中间 |

### 为什么这是"核心概念"而不是"又一个条"

因为它**吃掉了三条破局路径里的两条**：

| 原来 | 现在 |
|---|---|
| 敌人的「破绽值」 | **就是指针推到敌人一侧** —— 不需要单独一条槽 |
| 敌人的「体力耗尽」 | **就是指针被推过去之后的余波**：它跪下时体力也见底，起来后有一段脱力期 |
| 玩家的「体力」 | 合并进新的「定力」（见提案二） |

**原来的「三条破局路径」变成一条主线 + 一个变体**：
- 主线：**把指针推过去**
- 变体：用读招（认出变招）走捷径，一次推得更多

### 为什么它比其他方案好

1. **极简**：屏幕上只有一条条，玩家 3 秒就懂
2. **每时每刻都有反馈**：打一下→指针动了→你立刻知道"我赚了还是亏了"
3. **天然反龟缩**：不动就回落，逼你进攻 —— 这正是"中速博弈"而不是"魂系等待"
4. **天然反滚雪球**：到端点后重置回中间，不会一边倒
5. **它自己会讲节奏**：指针来回摆动 = 主动权易手 = 节奏。玩家不需要看"节奏五带"这种抽象概念，他直接看见指针在动

### 需要你判断的风险

- 指针到端点后"重置回中间偏你一点" —— 重置幅度要调。太大 → 优势不连贯；太小 → 滚雪球
- 如果指针推得太慢，玩家会觉得"打了半天没反应"。建议：一次完整交锋（3~5 秒）应该能推动 15~25%

## 提案二：资源合并 —— 体力 + 气力 → 一条「定力」

### 你说得对，我合并一下

街霸 6 的斗气槽能成立，是因为它**同时是进攻资源和防守资源**，所以每一次按键都在做取舍。我们现在两条槽各管一头，反而没有取舍。

**合并后的一条「定力」（上限 100）：**

| 行为 | 定力变化 | 属于 |
|---|---|---|
| 攻击命中 | **+4** | 进攻回充 |
| 完美格挡 | **+12** | **防守也能赚，但只有完美才行** |
| 处决 | **+20** | 兑现 |
| 被击中 | **−5** | 惩罚 |
| 普通格挡（每段） | **−8** | **纯消耗 —— 龟缩会被耗死** |
| 闪避 | **−12** | 比原来便宜（闪避不该被卡） |
| 重击（强化版） | **−25** | 进攻消耗 |
| 破防技 / 战技 | **−40** | 进攻消耗 |
| 归零 | **虚弱 3 秒**：不能闪避、不能用战技、受到伤害 +25%，动作被打断 | 惩罚 |

### 三个关键设计点

**① 闪避变便宜（20 → 12），而且不再是"掉到 0 就不能动"**
你提到"闪避基本没有体力限制" —— 对。移动是玩家的基本权利，卡住它会让人极度烦躁。
所以定力归零的惩罚是「不能闪避」但**只持续 3 秒**，而且之前你有充足预警（条在闪）。

**② 没有时间自动回充**
这是最重要的一条。**定力只能通过"做对的事"回**。所以：
- 站着不动 → 定力不回
- 一直格挡 → 定力往下掉
- 只会挨打 → 定力空了 → 虚弱 → 更容易挨打

**这直接把"龟缩"从"低效但安全"变成"必死"。**

**③ 普通格挡和完美格挡的差距被拉大**
- 普通格挡：−8，单纯止损
- 完美格挡：**+12**，净赚 20 的差距

这就把"完美格挡"从"减伤手段"变成"**回充手段**"。玩家会主动去练它，因为不练就没资源。

### 与提案一的关系

```
定力（你自己的）  = 你还能不能行动
压力条（双方的）  = 这一局谁占上风
```

**它们是一条链**：定力高 → 你能打强化攻击 → 强化攻击推力大 → 指针往你走 → 指针到端点 → 你处决 → 回定力。
**闭环。** 这就是"核心循环"。

## 提案三：关于"包装概念" —— 我准备了两个，想听你选

你要求"添加 1-2 个自洽的玩法与包装概念"。我准备了两个，都能把上面两条机制接到《残响》的世界观里。

### 概念 A：「同频」

**玩法**：定力在你体内叫「同频度」—— 你和体内残响的同步程度。
- 同频度高 → 你能动用残响的强化招式
- 同频度归零 → 残响开始夺走你的身体（虚弱状态的表现：**角色轮廓闪烁、动作变得不受控**）

**包装上的好处**：虚弱状态不再是"debuff"，而是**叙事事件**。玩家会记住"我的残响差点把我吞了"。

**风险**：偏被动，玩家只是"管理一个条"。

### 概念 B：「压势」★ 我更推荐

**玩法**：把提案一的压力条做成**双方共享的一条**，叫「压势」。
- 压势是两人之间那条线的位置
- 它不属于任何人 —— 你在推它，敌人也在推它
- 推到谁那边，谁就"失势"

**它为什么自洽**：因为这个世界里，**契约是双向的**。
> 设定：残响不满足于被借用。当你在对抗中占上风，敌人的残响会开始"倒戈"——想叛逃到你这边。
> 所以"压势"不是抽象数值，而是**两个人体内残响的角力**。

这带来一个很漂亮的叙事-机制咬合：
- 你把敌人打崩 = **它的残响想投靠你**
- 敌人把你打崩 = **你的残响想抛弃你**

**而且它给了失败一个体面的解释**：不是你菜，是你的残响觉得你不行。

### 概念 C：两个都要（我最推荐）

- **压势**（共享压力条）= 全局的核心概念，一句话就能讲清
- **同频**（个人定力）= 战术层的取舍资源，讲"我还有没有能力做动作"

两个词都很短，玩家记得住：
> **"推压势，攒同频。"**

## 提案四：预兆信号从 7 种砍到 2 种

你说得对，7 种颜色是"信号灯机制"，而且理解成本高。你的要求是：**最多 2~3 种，且每种至少 2 个解法**。

### 关键区别：信号灯机制 vs 姿态读招

| | 信号灯机制（我不要） | 姿态读招（我要） |
|---|---|---|
| 玩家在做 | 看到颜色 → 按对应键 | 读敌人的**身体** → 选一种投资方式 |
| 例子 | FF16 的躲闪提示、某些手游的红圈 | 战神、鬼武者、怪物猎人 |
| 缺点 | 变成节奏游戏，没有决策 | 需要学习，但学会了很有成就感 |

### 新方案：2 种状态，3 种解法

**取消所有颜色。** 敌人出招时只有两种可读状态：

| 状态 | 怎么看出来 | 含义 |
|---|---|---|
| **普通** | 动作自然、武器收在中段、有起手风 | 可以格挡、可以完美格挡、可以闪避 |
| **特殊** | **武器/身体有 0.3 秒的"沉"**（下压蓄力）+ 音效变低 | 可以格挡（伤害减半）、**不能完美格挡**、可以闪避 |

**「特殊的沉」是唯一的新概念，而且它不是颜色，是动作节奏。** 这是鬼武者/怪猎的做法。

### 每种状态至少有 2 个解法

| 状态 | 解法 1 | 解法 2 | 解法 3 |
|---|---|---|---|
| **普通** | 完美格挡 → 定力 +12，压势 +2 | 闪避 → 定力 −12，换位置 | 硬吃 → 定力 −5，但可以继续连段 |
| **特殊** | 闪避 → 定力 −12，安全 | **用定力硬顶**（消耗 25 定力，反震敌人，压势 +3） | 用战技打断（消耗 40） |

**注意「特殊」的解法 2**：它把"防守"变成了一次**资源对抗**——你花定力，换压势。这正好是你要的"一种资源多种用途"。

### 比原来好在哪里

| | 原来 7 色 | 现在 2 种状态 |
|---|---|---|
| 玩家要记的 | 7 种颜色 + 7 套应对 | **1 个概念（"沉"）** |
| 每个征兆的解法 | 1~2 种 | **3 种，且各有取舍** |
| 是不是信号灯 | 是 | **不是 —— 是读动作** |
| 美术工作量 | 7 套颜色特效 | **2 套（一个地面弧线 + 一个音效）** |

## 汇总：改完之后整个系统长什么样

```
     【压势】一条贯穿全场的横条，双方在拔河
        ↑                              ↑
    你推进它                        敌人推进它
        |                              |
   ┌────┴──────────────────────────────┴────┐
   │         你的「同频」（定力）100          │
   │  攻击命中+4  完美格挡+12  处决+20        │
   │  普通格挡−8  闪避−12  重击−25  战技−40   │
   │  归零 → 虚弱 3 秒（残响想夺走你的身体）    │
   └────────────────────────────────────────┘
        |
   敌人出招，只有两种可读状态
        ├─ 普通（动作自然）→ 完美格挡 / 闪避 / 硬吃
        └─ 特殊（武器"沉"0.3 秒）→ 闪避 / 用定力硬顶 / 战技打断
```

**玩家一分钟内能学会的话**：

> 打他就推压势，推到头他就跪；他出招时看武器有没有"沉"，沉了就用定力顶；定力空了你就虚弱，所以不能一直防。

**这就是核心概念。**
