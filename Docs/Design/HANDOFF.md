## 1. 已确认的设计决策（**这是最重要的部分**）

以下全部由策划拍板确认，**不要再重新提方案**，直接执行。

### 1.1 核心概念：三层资源

| 层 | 名称 | 归属 | 回答的问题 | 数值 |
|---|---|---|---|---|
| 一 | **压势指针** | **双方共享** | 这一局谁占上风 | 满程 100，中点 50 |
| 二 | **同频** | 个人 | 我能不能做一个强化动作 | 上限 100 |
| 三 | **契约槽** | 个人 | 我什么时候能放大招 | 上限 100 |

**关键规则（缺一不可）**：
- **同频没有任何「随时间自动回充」** —— 这是反龟缩的核心规则
- **契约槽的唯一来源是「强化动作命中」**（+15~+30），打空不加
- 契约槽满而未放时：所有同频消耗 **−20%**
- 指针什么都不做时**每秒向中点回落 1 格** —— 龟缩不能赢
- 指针推到任一端点 → 该方跪下，另一方获得处决权

**指针数值表**：强化动作 +3~+4｜处决 +5｜成功躲黄光 +3｜完美格挡 +2｜被打中 −2｜普通格挡/闪避 0｜闲置 −1/s

**同频数值表**：
- 回充：命中 +4｜完美格挡 +12｜处决 +20
- 消耗：闪避 −12｜格挡每段 −8｜强化重击 −25｜强化战技 −35~45｜强化换人 −30~50
- 归零 → 虚弱 3 秒（不能闪避、不能用战技、受创 +25%）

### 1.2 敌方信号：只有 2 种（**取消了原来的 7 色预兆**）

| | 红光 | 黄光 |
|---|---|---|
| 含义 | 不可防御，范围大 / 段数多 | 投技 / 下段，不可防御 |
| 三种解 | ① **强化动作破**（起始 8 帧霸体）② 跑出范围 ③ 硬吃 | ① 闪避 ② 跳跃 ③ 换人无敌 |
| 解掉的收益 | 敌人**超长硬直 2.5 秒** → 打一整套 + 契约槽 +25 | 它空招 → **压势 +3** → 确反窗口 |
| 没解掉的收益 | **白覆层 3 秒（可延长至 10 秒）** | 无补偿，但也不额外惩罚 |
| 失败代价 | 巨量伤害（约 30% 最大生命）+ 压势大幅倒退 | 巨量伤害 + 指针直接朝敌人跳 8 格 |
| 占比 | 15~20% | 10~15% |

> **辨识方式不是颜色，是动作节奏**：红光 = 低频音 + 武器泛红 + 身体后坐；
> 黄光 = 身体压低 + 音效上扬 + 手部张开。**这是「读招」而不是「信号灯」。**

### 1.3 白覆层延长（整套系统最好玩的一段）

红光没被破 → 敌人进入**白覆层**（身上白色覆层、无霸体、任何攻击可打断），初始 3 秒。

| 你在这 3 秒内做的事 | 白覆层剩余时间 |
|---|---|
| 什么都不做 | 3 秒后消失 |
| **轻攻击命中** | **−0.5 秒（普通攻击会缩短它！）** |
| 强化重击命中 | +1.5 秒 |
| 强化战技命中 | +2.5 秒 |
| 强化换人命中 | +2.0 秒 |
| 上限 | **10 秒** |

> **「普通攻击缩短它」是这条机制成立的关键。** 没有它，白覆层就是免费输出时间；
> 有了它，白覆层变成资源考试 —— 逼玩家持续投资强化动作。

### 1.4 玩家行为集：27 个动作，四类

**① 基础动作（14 个，不耗同频）**
轻攻击（3 段）｜轻→轻→重（击退）｜轻→重（上挑浮空）｜方向派生（前突进/后撤/左右横扫）｜
延迟重击（骗反击）｜重击（破轻霸体）｜蓄力重击（破重霸体）｜闪避（无敌 11 帧）｜
跳跃/下劈（躲下段）｜格挡/完美格挡（6 帧）｜投技与挣脱

**② 强化动作（8 个，耗同频，全部能破红）**
强化重击 −25→+18｜强化战技 A 伤害型 −40→+25｜B 控制型 −40→+22｜C 位移型 −35→+20｜
D 范围型 −45→+20｜强化续奏换人 −30→+20｜强化接管换人 −50→+30｜强化处决 −30→+15

> **战技共 12 个**：每把武器 4 个（伤害/控制/位移/范围）× 3 把武器
> **共同规则**：起始 8 帧带霸体 —— 所以「看到红光立刻按」成立

**③ 换人（4 个，三种身份）**
续奏换人｜接管换人｜代奏（援助，CD 25s）｜**强化换人**
- 身份①：节奏工具　身份②：躲黄光的三种解之一　身份③：破红手段
- **强化换人比其他强化动作快 3~5 帧** —— 这是三人队伍独有的爽点，别家抄不走
- 三角色的强化出场技不同：疾风最快、磐石范围大、炽破红后白覆层额外 +1 秒

**④ 大招（2 种，契约槽满，不耗同频）**
- **契约共鸣**：大范围爆发，命中压势 +15
- **残响具现**：8 秒内所有强化动作免同频
