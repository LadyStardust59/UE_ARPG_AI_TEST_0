# 50 个核心玩法概念（每个一句话）

> 格式：**概念名** — 一句话说清机制，以及它为什么有趣。
> 用途：设计灵感库。看上哪个我们可以深聊，不合适就跳过。
> 排序：按"机制类型"分组，不按好坏。

---

## A. 刻度与拔河类（和「指针」同源）

1. **指针拔河** — 一根共享条，双方行为推它，推向谁谁失势。（已在用）
2. **天平** — 指针不在中点而是两端的重量差；你打得越凶，敌人反击时回摆越猛。
3. **潮汐** — 把指针换成周期涨落的潮位；涨潮时敌人强、退潮时你强，逼你等窗口。
4. **温度计** — 战斗越激烈双方数值越"热"；过热会自伤，逼你主动降温。
5. **拔河绳结** — 指针经过特定刻度时会"打结"卡住几秒，制造短暂的确定优势。
6. **双指针** — 一条管"压制"，一条管"资源"，两条互相制约：只推一条会崩。
7. **指针即血条** — 指针推到端点才是真实伤害来源，生命值只是缓冲。

## B. 节奏与时间类

8. **呼吸系统** — 敌人有"吸气/呼气"周期，吸气时防御高、呼气时防御低——攻击窗口由它的呼吸决定。
9. **心跳** — 你的资源在心跳周期内波动，在峰值出手伤害更高，逼你踩点。
10. **静默** — 全场每 30 秒强制静音 2 秒；听不到音效预告，只能靠视觉读招。
11. **借来的时间** — 完美格挡不减免伤害，而是"暂停"伤害结算几秒，期间打死敌人则伤害取消。
12. **倒计时换取** — 主动缩短自己的某项资源上限，换一次高额爆发。
13. **时间债** — 你可以透支未来的资源，之后一段时间资源回复变慢。
14. **延音** — 连段中每次"精准按"给连段 +1 秒持续时间，考验稳定性。

## C. 资源与转化类

15. **蓄水池** — 资源不会自动恢复，只能通过"高风险行为"注入。
16. **转化炉** — 把生命转成资源，或把资源转成生命，两者永不兼得。
17. **互锁资源** — A 资源消耗才能恢复 B，B 消耗才能恢复 A，必须交替使用。
18. **资源只在满时有用** — 某资源攒满才触发效果，中间状态毫无意义，逼你"要么攒满要么花光"。
19. **溢出惩罚** — 满值后再获取资源会扣血，逼你及时消耗。
20. **共享资源池** — 你和敌人都从同一个池子抽资源，抽得越多对方越少。
21. **押注** — 出手前先"押"一部分资源，命中了翻倍返还，打空了没收。
22. **双资源不竞争** — 一条管短期决策，一条管长期目标，互不抢，避免决策瘫痪。（已采纳）

## D. 防御新维度

23. **方向格挡** — 格挡要选方向，选错方向被破防。
24. **节奏格挡** — 不是按一下，而是跟着敌人的攻击节奏连按，像音游。
25. **蓄力反击** — 格挡时按住不放，松手时反击伤害与按住时长成正比。
26. **吸收** — 挡住攻击不会免伤，而是把伤害存起来，之后可以一次性还给它。
27. **拆招** — 多段攻击需要逐段拆解，每段用不同手段，像解谜。
28. **换位格挡** — 格挡成功后自动位移到敌人背面，防御即进攻。
29. **代价格挡** — 完美格挡不改血，但会扣你的资源上限（临时）。
30. **拆解姿态** — 敌人每个部位有独立"防御值"，打掉哪块，它的招式就少一种。

## E. 敌人行为与生态

31. **敌人也会换武器** — 打掉它的武器后，它换第二把，招式全变。
32. **内讧** — 双 Boss 中一个被打崩时，另一个有概率攻击它（抢功）。
33. **模仿者** — 敌人会复制你最近用过的招式反击你，逼你换招。
34. **学习型 AI** — 敌人记住你最常用的三招并针对性防御，逼你拓宽招池。
35. **领地宣告** — 敌人在场地上划出"领地"，站进去会持续掉资源，逼你走位。
36. **尸体即资源** — 击杀小怪后尸体留在场上，可被双方利用（投掷 / 吸收 / 引爆）。
37. **赌局型敌人** — 它会"押"你接下来的动作，押对了它大收益，押错了它大破绽。
38. **情绪值** — 敌人有情绪条，被连续压制会上头（招式变强但破绽变大），也可能怯场（逃跑/防御）。

## F. 战场与关卡

39. **可破坏地形** — 场景物件被打碎后永久消失，破坏它是一种资源决策。
40. **高度即资源** — 高低差不是装饰，站在高处每次攻击都有额外收益，但要冒险爬上去。
41. **回音室** — 某些区域攻击会反弹（自己的攻击也会伤到自己）。
42. **观众** — 场外围观者（NPC）会为精彩操作欢呼并给你增益，为失误喝倒彩并削弱你。
43. **场地收缩** — 战斗时间越长，可站立区域越小，逼你加快节奏。
44. **地形记忆** — 场地记住你的走位，重复走同一条路会被"预判"。

## G. 换人与队伍

45. **残影接力** — 换人时留下的残影会继续打一段，形成"两人同时在场"的假象。
46. **角色间欠债** — A 角色救过 B，B 上场时会有增益（叙事-机制咬合）。
47. **共享伤害** — 三人共用一个血池，但每人有自己的资源，逼你分工。
48. **切换即赌注** — 换人时随机继承一小段对方的状态（可能是增益也可能是减益）。

## H. 成长与构筑

49. **反成长** — 每解锁一个新能力，就会失去一个旧能力（取舍而非累积）。
50. **招式融合** — 两把武器的招式可以合成第三招，组合数量爆炸。
51. **伤痕系统** — 死亡不读档，而是在角色身上留下永久伤痕（改变招式或数值）。
52. **契约背叛** — 你可以中途换掉一个残响，代价是永久失去它。

## I. 信息与 UI

53. **无 UI 战斗** — 所有状态都靠角色表现传达，没有血条和资源条。
54. **敌人血条撒谎** — 血条显示的不是真实血量，逼你靠观察判断。
55. **预知闪回** — 你被打死前 3 秒的画面会回放一次，用来复盘。

## J. 实验性（风险高但独特）

56. **双人操作** — 一个玩家操作角色，另一个（或 AI）操作残响，两人需要配合。
57. **逆向操作** — 某些状态下按键含义反转（残响夺取身体控制权）。
58. **不可暂停** — 打开背包/菜单时游戏继续，逼你提前准备。
59. **一击必杀模式** — 双方都是一击死，战斗变成纯粹的读招博弈。
60. **回放对战** — 录下你上一场的操作，让敌人学习并复刻你的招式来打你。

## 我最看好的 5 个（如果要挑）

| # | 概念 | 为什么 |
|---|---|---|
| **11** | 借来的时间 | 把"完美格挡"从减伤变成"倒计时救援"，每一次完美格挡都是一个小高潮 |
| **47** | 共享伤害 | 三人共用一个血池，配合已有的"三人换人"会立刻产生分工压力 |
| **24** | 节奏格挡 | 格挡变成手感玩法，非常适合已经决定"取消信号灯、靠读招"的方向 |
| **36** | 尸体即资源 | 让清小怪这件事产生了战术价值，不只是"打扫" |
| **45** | 残影接力 | 换人时两人同时在场，视觉冲击强，而且和三人队伍系统天然咬合 |

## 使用建议

**不要一次加超过 2 个。** 这些概念每个都够撑一个系统，加太多会重演"资源臃肿"的问题。

我的建议顺序：
1. 先把 **指针拔河 + 同频 + 契约槽** 这三层跑通（现在这一步）
2. 垂直切片验证手感后，加 **1 个** 上面的概念（我推荐 #11 借来的时间，因为它改的是已有的完美格挡，不新增系统）
3. 再评估要不要加第二个
