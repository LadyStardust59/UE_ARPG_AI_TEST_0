# 《残响》· 包装方案与世界观设定

> **这份文档解决一件事**：让这套战斗系统"看上去像一个游戏"，而不是一堆数值和状态机。
>
> 原则：**所有包装必须长在已有资产上，不推翻任何东西。**
> 项目里已经有的：`DA_Striker`（疾风）、`DA_Breaker`（磐石）、`L_Arena`、`L_Fortress`、契约兽系统、三人换人。
> 这份设定把它们全部接上，并给第三个角色留了位置。

---

## 第一部分：为什么是"残响"

我试过三个方向，最后选了这一个。理由写在这里，方便你判断要不要换。

| 方向 | 例子 | 为什么没选 |
|---|---|---|
| 江湖武侠 | 门派、内力、暗器 | 好写，但**解释不了"换人"** —— 一个人怎么能突然换一套武功？只能靠剧情硬编 |
| 神话史诗 | 神祇、英灵、诸神黄昏 | 大气，但**解释不了"完美格挡"** —— 为什么挡住一下就能夺回主动权？ |
| **残响（借魂）** | 契约、余响、侵蚀 | ✅ 一个概念同时解释：**换人、预兆、格挡、破绽、换人惩罚、Boss 由来** |

**核心设定一句话：**

> 人可以通过「契约」借用死者留下的技艺 —— 但每借一次，就多丢一点自己。

这一句话，把整个战斗系统的每个机制都解释通了：

| 机制 | 世界观解释 |
|---|---|
| 三人换人 | 契者的身体只能容纳三个残响 |
| 敌方预兆 | 契者能"看见"还没发生的伤害（因为残响比宿主早一步感知） |
| 完美格挡 | 两个残响在同一具身体里**同频那一瞬**——所以叫「契约爆裂」 |
| 破绽 | 残响短暂夺走了敌人的身体 —— 所以叫「魂隙」 |
| 被压制惩罚加重 | 越绝望，体内的残响越吵 —— 所以叫「执念」 |
| 换人冷却 | 残响被强行替换后会"闭锁"，短时间内叫不出来 |
| 巨型 Boss | 一个吞噬了太多残响的人 —— 他的身体已经不属于他了 |
| 双 Boss | 一个人被契约撕成了两半 |

**这最后两条是我最想让你注意的**：三个 Boss 不是"三个敌人"，而是**主角们未来可能的三种结局**。
玩家打的其实是自己的可能性。

### 预兆色板的世界观化（重要）

原来叫"红黄金白紫青金紫"，太像说明书。包装成**残响的情绪色**：

| 颜色 | 术语 | 含义 | 玩家直觉 |
|---|---|---|---|
| 红 | **怒** | 重击，可格挡 | 硬碰硬 |
| 黄 | **乱** | 多段快攻 | 会被磨 |
| 金 | **执** | 投技，挡不住 | 必须躲 |
| 白 | **锐** | 直线突进 | 让开 |
| 紫 | **镜** | 镜面术（复制你的招） | 别重复出招 |
| 青 | **域** | 领域与召唤 | 离开这块地 |
| 金紫 | **醒** | 觉醒全场 | 拼命时刻 |

> 这样玩家在论坛上会说"看到金字就要躲"，而不是"看到金色预兆需要执行闪避操作"。
> **一句话就能传播，这对独立项目很重要。**

## 第三部分：世界观

### 时代

**「静默」之后第九十年。**

九十年前，一场被称为**静默**的灾难让所有声音消失了三天。三天后声音回来了，但死人开始留下东西 ——
不是鬼魂，是**残响**：一个人生前最执着的那部分技艺、习惯、执念，凝成了一段可以被"听见"的余音。

有人第一个学会了与残响共鸣。那年之后，世界重新有了秩序，也有了新的病。

### 契约

与残响共鸣需要**契约**。契约的规则只有三条：

1. **借来的技艺不会消失，但会挤占。** 每共鸣一位残响，契者自己的记忆就淡一层。
2. **一具身体最多承载三位残响。** 再多，宿主会在三天内变成"空壳"——身体活着，里面没人。
3. **残响也会想要。** 它们不满足于被借。共鸣越深，它们越想接管。

### 三个阵营

| 阵营 | 主张 | 代表人物 | 玩家关系 |
|---|---|---|---|
| **守序之契** | 契约是重建秩序的技术。应该被管理、被登记、被配给 | 无名（前导师） | **第一个 Boss** |
| **焚契派** | 契约是亵渎。所有残响都该被销毁，哪怕连同宿主一起 | 未登场 | 续作伏笔 |
| **墟骸** | 不是阵营，是**结局**：吞噬了太多残响、已经无法回头的人 | 墟骸 | **第二个 Boss** |

### 核心矛盾（这才是故事真正在讲的东西）

> **你借用别人的力量，是为了守护自己珍视的东西 —— 但每借一次，你就更不记得自己为什么要守护它。**

主角团的处境：他们是**中立派**。既不愿意被守序之契登记管理，也不接受焚契派"连人一起烧"的做法。
他们想找一条第三条路 —— 而游戏要问的是：**这条路存在吗？**

## 第四部分：人物小传（DND 式车卡）

格式：姓名 / 年龄 / 身份 / 残响 / 目标 / 过往 / 秘密 / 在队伍里的位置

---

### 【疾风】· 已存在（`DA_Striker`）

| 项 | 内容 |
|---|---|
| **真名** | 未知。她自己也不记得了 —— 这是她付出的第一笔代价 |
| **年龄** | 20 出头（她猜的） |
| **身份** | 前守序之契的**祭司**。负责为新人主持第一次契约仪式 |
| **残响** | **「游隼」** —— 一位以速度留名的信使，死时还在奔跑 |
| **战斗风格** | 轻快。HP 220 / 移动 650 / 伤害 24 / 攻击间隔 0.38s。青蓝色调 |
| **目标** | 找回自己丢掉的那段记忆 —— 她记得自己"忘了一件很重要的事"，但想不起来是什么 |
| **过往** | 她主持过一场失控的契约仪式（她记得那场仪式的每一个细节，除了死者的脸）。受害者是谁，她不知道 —— 因为那是她自己的记忆被抹掉的部分 |
| **秘密** | 那场仪式的死者，是她的**姐姐**。而她的第三位残响，就是姐姐 |
| **队伍位置** | **先手 / 压制者**。适合开场抢主导权、堆压制层数 |

> **她的叙事钩子**：玩家在游戏中期拿到她的第三位残响时，会看到技能名是"姐姐的名字"。
> 但疾风自己不明白那是什么意思。玩家比她先懂。

---

### 【磐石】· 已存在（`DA_Breaker`）

| 项 | 内容 |
|---|---|
| **真名** | 石坚（他自己坚持用真名 —— "名字是最后的锚"） |
| **年龄** | 五十后半 |
| **身份** | 前守序之契的**守卫队长**。守过一座已经不存在了的城 |
| **残响** | **「镇墙」** —— 一位守城至死的老将。他完整地记得那人死前的每一个瞬间（这正是他拒绝更多残响的原因） |
| **战斗风格** | 沉重。HP 300 / 移动 520 / 伤害 36 / 攻击间隔 0.58s。橙色调 |
| **目标** | 让自己的三个残响"安安静静地离开"，而不是被焚契派烧掉 |
| **过往** | 他守的城毁于静默后的第一次契约战争。他活下来，因为他在最后一刻与「镇墙」共鸣了 —— 也因此永远记住了对方是怎么死的 |
| **秘密** | 他其实已经快要被侵蚀了。他只用两位残响，第三位的位置一直空着 —— 他说"留给需要的人"，其实是**留给自己的空壳**（一旦撑不住，就让自己变成空壳而不是失控） |
| **队伍位置** | **中枢 / 读招者**。适合中段接管、处理敌方第二阶段的变招 |

> **他的叙事钩子**：他教玩家"如何读招"（教学关的声音是他）。
> 而他隐瞒的是：读招的能力越强，说明侵蚀越深。

---

### 【炽】· 新角色（对应设计文档里的"爆发者"）

> **这个是新增的。** 前两个已经存在，第三个我按你的战斗系统设计补上 ——
> 因为三人队伍需要一个"兑现伤害"的收尾位，同时故事上需要一个**知道真相的人**。

| 项 | 内容 |
|---|---|
| **真名** | 炽（单字。别人叫她"炽"，她自己叫她"我"） |
| **年龄** | 看起来十七八岁 —— 但她已经活了很久了。契约让她"卡"在了某个年纪 |
| **身份** | **不是契者，是残响**。她是一个被塞进活人身体的完整残响 —— 也就是说，这个身体原本的主人已经没了 |
| **残响** | **她自己**。她是"别人的残响"这一点，队伍里只有磐石隐约知道 |
| **战斗风格** | 高爆发。HP 190 / 移动 600 / 伤害 42 / 攻击间隔 0.5s。洋红色调。双刃 |
| **目标** | 找到"自己是谁"。她只知道自己不是这具身体原来的主人 —— 但她不知道自己是谁的残响 |
| **过往** | 她醒来时，守序之契的人告诉她"你是一个叫炽的契者"。她信了十七年。直到她发现自己的身体不会累、不会老、伤口愈合得太快 |
| **秘密** | 她其实是**无名（第一个 Boss）** 的第一位残响。无名把唯一完整的残响分离出来，放进一具空壳身体里，埋名藏了起来 —— 为了让她不被焚契派烧掉。而无名自己因此失去了最重要的一段记忆 |
| **队伍位置** | **收尾 / 爆发者**。适合在魂隙窗口兑现伤害、执行断链 |

> **她的叙事钩子**：她与无名相遇时，无名会说一句"你还在"。
> 而她不认识他。玩家会在那一刻明白很多事。
>
> **她的机制呼应**：因为她是残响而不是完整的契者，所以她的"共鸣槽"增长方式不同（世界观解释了她的专属资源加成）。

## 第五部分：故事路线（三幕 + 一个真正的反派）

### 幕一：登记（Tutorial 弧）

守序之契要求所有契者登记自己的残响。主角团拒绝。**无名**作为回收官找上门。

> **第一场 Boss 战**：他用的招式与教学关教过的完全一致 —— 因为他就是教玩家的那个人。
> 玩家必须用他教的东西打败他。

**转折**：打败他之后，他摘下面甲。玩家发现他已经在侵蚀末期 —— 他的脸有半边是"空"的。
他说："我教你的每一招，都是我从别人那里借的。"

---

### 幕二：焚烧（Mid-game 弧）

焚契派烧掉了一处残响栖息地。主角团赶到时，那里只剩下**墟骸** —— 一个吞噬了太多残响、已经无法回头的人
在慢慢变成一座会走路的碑。

> **第二场 Boss 战**：它的三层结构，是三个人格的残骸叠在一起。
> 玩家的每一次部位破坏，都是在"替一个已经不存在的人松绑"。

**转折**：核心「墟眼」被打碎时，映出一张脸 —— 疾风认出了那张脸，但她想不起来在哪见过。
（那是她姐姐。玩家知道，她不知道。）

---

### 幕三：两半（Final 弧）

追查焚契派的路上，主角团遇到**镜与影**。

她们是**同一个人**——焚契派的实验体：把一个人的两份契约记忆强行分离，看能不能制造"不含残响的纯人类"。
结果造出了两个都不完整的人。她们互相需要，也互相憎恨。

> **第三场 Boss 战**：她们共享一个生命池。玩家必须先决定"先杀谁"——
> 而不管杀谁，另一半都会狂怒。谢幕时两人会同时倒下，并在一起。

**转折**：她们死前说了一句话，指向**真正的反派**。

---

### 真正的反派：**残响本身**

三个 Boss 都不是坏人。他们分别是：
- 一个被契约吞噬的老师
- 一个吞噬了契约的死者
- 一个被契约撕开的活人

**真正的反派是「残响」这个现象本身 —— 它们正在集体觉醒，并且不再满足于"被借用"。**

序章里那句"人可以通过契约借用死者留下的技艺"，到结局会变成：
**"死者正在通过契约借用活人的身体。"**

### 留给续作的钩子

- **炽**的真实身份（她是无名的第一位残响）在结局揭晓 —— 而她必须选择：回到无名身体里（救他但失去自己），还是留下来（保住自己但看着他变成空壳）
- **疾风**的姐姐在幕二后的残响中苏醒，她记得一切，包括疾风忘了的事
- **焚契派**的实验说明：**"不含残响的纯人类"是可以制造的** —— 代价是那个人永远不完整
- 结局的选择决定了续作的世界状态

## 第六部分：这些设定怎么变成游戏里的东西

包装不是写小说，是要落到资产上。以下是**具体落地清单**：

| 设定 | 落地物 | 优先级 |
|---|---|---|
| 三位残响 / 三人切换 | 把现有 `SwitchHero()` 扩成三人；每位残响一张 `DA_HeroDefinition` | **最高**（路线 C 之后） |
| 征兆色板 | 7 种颜色的地面 Decal + 音效；UI 图例教程 | **最高**（路线 C 第 3 步） |
| 契约爆裂 | 完美格挡的白光 + 环状碎裂 VFX + 一层音效 | **最高** |
| 魂隙 | 敌人跪下 + 轮廓开裂材质 + 屏幕轻微失真 | 高 |
| 断链 | 处决镜头 + 慢动作 + 分层顿帧 | 高 |
| 映照域 | 需要新增场地 Actor（路线 C 之后） | 中 |
| 主导权指针 | 顶部 UI 元素 | 中 |
| 三场 Boss | 需求量大，放在垂直切片验证之后 | 低（但必须留在路线图里） |
| 无名的脸是半空的 | 需要定制模型 —— 用材质遮罩可以先做 | 低 |

## 第七部分：需要你拍板的三件事

1. **世界观方向**：接受"残响 / 借魂 / 侵蚀"这套吗？
   - 接受 → 我把它写进 `Docs/Design/`，并把术语映射表同步到设计文档
   - 不接受 → 告诉我你想偏哪个方向（武侠？现代？），我用同样的方法重新推一套

2. **第三个角色「炽」**：要还是不要？她的设定与"无名是第一个 Boss"深度绑定。
   - 要 → 我补一份完整的 `DA_Ember` 数值卡
   - 不要 → 三人队伍改成"疾风 + 磐石 + 一位临时盟友"，但叙事钩子会弱一些

3. **游戏名**：现在叫 `MyCppProject`。
   - 建议：**《残响》**（英文 *Echoes of Silence*）
   - 或者你想用别的，告诉我
