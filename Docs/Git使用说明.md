# Git 使用说明（写给没用过 Git 的人）

> 这份文档只讲你**实际会用到**的东西。看完大约 5 分钟。
> 你不需要记任何命令 —— 所有操作都做成了双击就能用的工具。

---

## 一、Git 是什么？（一句话）

**它给你的项目做"游戏存档"。**

打过游戏就懂了：
- **存档** = 把现在的进度记下来，以后随时能读回来
- **读档** = 发现改坏了，退回上一个存档
- **云存档** = 除了本机，还传一份到网上，电脑坏了也不怕

Git 就是干这个的。你的项目里已经有一个云端存档库（GitHub 上的私人仓库），
以后每次"存档"都会同时存在**本机**和**云端**两份。

## 二、你只需要记住两件事

### 我要存档 → 双击 `Scripts\backup.bat`

```
D:\UE_Project\MyCppProject\Scripts\
├─ backup.bat      ← 双击这个 = 存档（提交 + 上传）
└─ rollback.bat    ← 双击这个 = 读档（退回上一个存档）
```

`backup.bat` 会问你一句话：**"请用一句话说明这次改了什么"**。

随便写，比如：
- `做好了完美格挡`
- `调整了角色移动速度`
- `加了新的敌人模型`

**就这一件事。** 其他都是自动的。

### 我改坏了 → 双击 `Scripts\rollback.bat`

它会把最近的存档列出来，你输个数字就退回去了。
**而且它会先把你"改坏之前的当前状态"也存一份** —— 所以万一退错了，还能再回来。放心用。

## 三、什么时候该存档？

| 时机 | 要不要存 |
|---|---|
| 做完一个**能跑起来**的功能 | ✅ 一定要存 |
| 调好了一个手感（比如格挡窗口） | ✅ 存 |
| AI 帮你加了一批新东西，试过没问题 | ✅ 存 |
| **准备让 AI 做一个大改动之前** | ✅✅ **特别重要，先存一份** |
| 改到一半、还跑不起来 | ❌ 先别存 |
| UE 编辑器里还没保存 | ❌ 先在编辑器里 `Ctrl+S`，再存档 |

> **最重要的一条习惯**：让 AURA 做大改动之前，先双击一次 `backup.bat`。
> 这样不管它改成什么样，你都能一键退回来。

## 四、三个必须知道的事

### 1. 未保存的内容不在存档里
在 UE 编辑器里改了东西，**必须先在编辑器里保存（Ctrl+S）**，
存档工具才看得到。没保存的改动，Git 是不知道的。

### 2. 存档不会让你的项目变小或变慢
项目里的大文件（模型、贴图、动画）走的是 **Git LFS**（大文件专用通道），
不会拖慢仓库。这个已经配置好了，你不用管。

### 3. 不要删 `.git` 文件夹
项目根目录下有个隐藏文件夹叫 `.git`，**所有存档都在里面**。
删了它就等于把所有存档删了。平时你不会看到它，也不用管它。

## 五、出问题了怎么办？（对照表）

| 现象 | 原因 | 怎么办 |
|---|---|---|
| `backup.bat` 说"上传失败" | 网络问题，或登录过期 | 改动已经存本地了，**不会丢**。稍后再双击一次即可 |
| 提示要登录 GitHub | 登录有效期到了 | 打开 PowerShell 执行下面这行，浏览器里点一下就好：<br>`git credential-manager github login --username LadyStardust59 --browser` |
| 存档后想反悔 | — | 双击 `rollback.bat`，选上一个存档 |
| UE 里资源变红了 / 丢东西了 | 可能是误删或提交不完整 | 先别动！双击 `rollback.bat` 退回上一个存档，然后告诉我 |
| 提示"改动数量很多（几千个）" | 可能误导入了一整个素材包 | 按 Ctrl+C 取消，然后告诉我，我帮你判断哪些该提交 |

**任何时候不确定，就停下来问我，不要自己乱按。** 项目已经备份过了，最坏情况也只是退回存档，丢不了东西。
